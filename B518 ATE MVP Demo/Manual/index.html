整體資料流

1

Windows 上位機

透過 TCP 連線指定 Arduino IP:5000，送出帶 JOB ID 與 slot 的條碼訊框。

2

Arduino Bridge

在 TCP 與 USB CDC 間透明轉送；同時依 Agent 指令執行螢幕截圖與 USB HID 鍵鼠動作。

3

Mac mini Agent

接收 JOB、操作測試 HMI、監控 CSV 或 BT 畫面，最後回傳完整 RESULT。

正式測試前 Arduino、Mac mini、Windows 上位機必須依本手冊順序完成；TCP JOB 一律以 CRLF 結尾。Arduino MVP 同時間只接受一個 TCP client。

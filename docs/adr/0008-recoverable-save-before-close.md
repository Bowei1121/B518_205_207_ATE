# 完整保存本次執行的輪次資料後才關閉 App

**Status: accepted — 2026-10-06（政策已確認；已由 Ticket 04 實作並合併，持續作為後續票的關閉協調契約）**

現有 writer 丟棄失敗工作且 flush 不會重試，無法保證關閉前完整保存；因此保留失敗資料供有序重試，並追蹤本次 App 執行期間所有未保存輪次，保存完成後釋放。正常關閉必須等這些輪次的 Session 與 audit 完整保存，取代各等待兩秒、警告後關閉；不要求關閉時掃描歷史 Session。

保存及重試期間視窗保持可操作；失敗顯示原因，操作員修復後可重試，也可取消關閉並留在 App。重試不得漏寫或重複寫入，歷史錯誤須保留紀錄但不能在修復成功後永久阻止關閉。

這項取捨接受故障未排除時 App 不能正常關閉及保留待保存資料的資源成本，以避免正常關閉丟失紀錄；既有稽核失敗不額外阻擋產品結果放行政策維持，關閉完整性與結果放行是不同條件。

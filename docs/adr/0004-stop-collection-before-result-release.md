# 區分停止讀檔與本輪結果可取用

2026-09-29 訪談確認：通道發現結果衝突時進入待確認並彈窗，其餘通道繼續收集；全部通道都有結果後停止讀取新 Log，不延長觀察以捕捉遲到資料。若仍有未處理衝突，維持待確認，待現場選擇原結果或新結果後才允許上位機取用本輪結果。此設計將資料收集結束與結果放行分開，避免完成後無限監控，也避免尚有爭議的結果被提前使用。

後續訪談確認新增的是「整輪監控上限」：從按下開始監控計時，超過期限仍未完成就停止讀取新 Log，彈出一次整輪逾時警報。已取得結果保留，未開始通道定為 NOTEST，已開始但未完成通道定為 TIMEOUT。程式維持待確認、上位機暫停；現場確認警報並處理既有結果衝突後，才可取用本輪結果。不得因逾時而自動選擇某個衝突結果。

正常情況下全部通道有結果即停止讀檔，不額外監聽完成後的檔案變更。新上限不是人工確認倒數；停止監控後的人工處理不新增獨立計時器。無法確認來源是否同輪的人工採用規則由使用者明確延後決定。

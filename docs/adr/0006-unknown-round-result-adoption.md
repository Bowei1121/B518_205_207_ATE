# 未知同輪結果候選的採用與失敗處理

**Status: accepted — 2026-10-06**

來源不能可靠連結至目前測試輪次時，現場不得人工採用其結果；此規則同時涵蓋該 Slot 的第一筆 final 與替換既有結果。測試時間是最低來源證據，SN 不是輪次證據的必要欄位；資料不足、人工拒絕或沒有選擇時，該 Slot 判為 FAIL，並記錄操作、候選與時間，不記錄理由。SN 讀取失敗的產品結果為 FAIL；因此 B482 空 SN 且平台狀態 FAILED 維持產品 FAIL，取代先前 Ticket 01／04 的 NOTEST 映射。來源時間缺失不得用觀察時間或檔案時間補造。能確認同輪的矛盾仍依 Ticket 10 逐項人工覆核。

**Consequences:** 未知來源候選不會顯示「採用候選」操作；不得以該候選產生 PASS。候選來源時間、候選值、結果處置與操作時間進入輪次紀錄；沒有理由欄位。使用者於 2026-10-06 確認，被標為 FAIL 的 Slot 依一般 FAIL 終態規則處理：符合其他輪次完成條件後可完成並供上位機讀取 FAIL；未知候選不新增額外人工確認阻擋。

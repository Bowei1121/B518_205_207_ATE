# 以配置、平台資料來源、監控輪次與桌面介面分工

2026-09-29 訪談確認以四個主要 Module 重構通用 Log 監控工具：測試配置管理部署參數與匯入匯出；平台資料來源理解各平台檔案及測試證據；監控輪次統一管理通道狀態、逾時、衝突及結果放行；桌面介面呈現狀態與接收操作。新增格式的變更應集中於平台模組及其測試，已支援平台的參數變更只更新配置。此分工保留平台實際語意差異，避免在各解析器與 UI 重複維護共同流程。

採逐步遷移並沿用 Python／Tk 與現有 macOS 打包方式，不同時更換 UI 技術；以既有解析、新容量與生命週期案例，以及 App／上位機共同驗收判定結果，不以檔案數或拆分數量判定成功。來源批次不確定的人工採用規則仍屬明確保留的業務決策，不由此架構決定。

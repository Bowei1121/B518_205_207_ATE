# 依啟動時螢幕決定固定 HMI 高度，通道增減不移動操作與計時

**Status: accepted — 2026-10-21（A1～A8 需求已確認，尚未實作及配對驗收）**

為讓操作員使用緊湊畫面並讓橋接程式建立穩定模板，App 開啟時依螢幕可用空間決定一次高度，之後禁止手動拉伸，也不因通道數量改變。表格可視區、開始按鈕、狀態與計時位置固定；縮小每列上下留白、取消文字表格最多十列的限制，放不下才捲動，通道少時表格內保留背景。這接受少量通道時的留白，避免自動收縮把辨識區推走；同一設備的相同顯示條件須維持穩定幾何。

這項決策更新 2026-10-16 訪談的十列上限，延續 ADR 0012 的固定計時區及證據區分。高度改變需重新量測裁切座標並更新橋接交接；固定布局不代表監控就緒、ATE 開測或遠端影像驗收已獲證實。詳見 [本輪訪談](../refactoring/HMI_COMPACT_FIXED_HEIGHT_DISCUSSION_2026-10-21.md)。

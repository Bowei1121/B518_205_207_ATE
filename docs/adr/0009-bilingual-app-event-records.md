# 同一 App 事件保存繁體中文與英文說明

**Status: accepted — 2026-10-07（保存政策已確認，尚未實作）**

為使台灣開發人員與美國現場人員可直接查閱同一操作經過，所有 App 產生的事件說明都保存繁體中文與英文，不限錯誤；兩語說明及必要原始診斷放在同一筆紀錄，共用事件身分、時間與適用的輪次身分。採同一紀錄取代兩份獨立語言檔案，避免保存進度不同或把一次操作誤記為兩次。

畫面按使用者選定語言呈現，既有事件在語言切換時也能重新顯示；硬碟的雙語說明不隨畫面語言切換重寫。SN、路徑、來源檔名、原始 Log 及機器狀態碼保留原值；原始診斷供詳細查證，不以猜測翻譯覆蓋。

未來增加其他畫面語言時，硬碟仍固定保存繁中／英文，另存訊息識別與參數供顯示，不因語言增加而持續擴大每筆紀錄。翻譯資源集中管理、驗證後隨 App 發布，不由現場匯入未驗證文案。

保存契約需要相容擴充，並區分可翻譯說明與原始證據；增加雙語儲存與翻譯維護成本，換取同一事件可被兩邊直接理解。實作格式仍由後續規格具體化。

舊檔案不改寫，可可靠辨識的歷史訊息在畫面依所選語言呈現；無法辨識的內容於詳細區保留原文，外層提示仍翻譯。沒有輪次的 App 事件另存雙語紀錄，不虛構輪次，沿用全域保存天數並從事件自身時間起算；保存失敗及待補存內容不清理。此新增 App 層事件範圍不改 ADR 0007 的整輪封存起算及非輪次資料保護界線。

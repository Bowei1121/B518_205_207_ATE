# 統一遷移 KVM 結果排列，不保留舊七格模式

2026-09-29 訪談確認：為支援已知最多二十片產品，新 KVM 結果排列每排固定十格，容量十片以內顯示一排，十一至二十片顯示兩排；超出配置容量的位置固定黑色。App 與上位機辨識同步更新，全部採用新排列，不保留既有七格相容模式，以固定格位方便上位機分析結果。此選擇承擔同步部署與重新驗證影像辨識的成本，避免維護兩套顯示契約；定位標記與幾何尺寸仍待後續設計，不能視為已完成介面規格或已部署。

後續訪談確認採用固定定位點旁的獨立黑白狀態標記，區分待命、監控中、本輪完成與待確認。產品色帶表達各通道結果，程式狀態標記表達是否可供上位機取用；待確認時上位機暫停該輪後續動作。標記須固定可見且不被確認視窗遮住。已提供二乘二黑白格示意，實際尺寸、辨識容差與 KVM 壓縮畫面的驗證仍待實作階段完成。

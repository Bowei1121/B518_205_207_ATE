# 以封存時間管理整輪紀錄保存期限

**Status: accepted — 2026-10-06（政策已確認，尚未實作）**

為控制長期磁碟用量並保留完整稽核關係，採 App 設定畫面的全域保存天數，預設 365 天，工程師可改為 180 天或其他正整數；從整輪結束且完整保存的封存時間起算，按同一輪次清理全部 App 產生的紀錄。新期限適用所有可清理的既有輪次，於下一次背景清理生效；縮短期限時設定畫面須提示既有資料可能到期。

背景清理在 App 啟動後、持續開啟期間每天及修改期限後安排，工作不重疊，不在關閉保存時啟動，留下清理摘要；失敗下次重試。正在監控、待確認、未完整保存、無法辨識、損壞或缺少可靠封存時間的資料保留；配置、偏好設定、人工匯出及平台原始 Log 不屬於清理範圍。

採整輪與可信封存時間，取代以個別檔案修改時間判定，避免拆散證據或猜測歷史資料年齡。自動刪除換取磁碟用量可控；刪除後 App 不再提供該輪重建資料，人工匯出檔仍由工程師各自管理。

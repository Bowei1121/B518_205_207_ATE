# 人工停止保留產品證據，無法確認同輪則取消而不強制交付

**Status: accepted — 2026-10-19（需求決策已確認；產品實作及配對驗收尚未完成）**

人工停止常表示操作員發現異常，但不能據此推定先前所有產品測試結果無效，因此選擇保留已取得終局結果、只把未完成位置定案為 STOPPED，並保留整輪人工停止原因；不清空整輪、不把 STOPPED 偽裝成 FAIL，重工範圍交由操作員決定。全部格位完整且沒有待確認事項時，人工停止可以交付，並與一般完成使用不同的整輪識別；磁碟稽核重建亦須保留此差異。

若橋接從未觀察到本次監控就緒，人工停止或來源準備逾時後的畫面不足以排除上輪殘留；即使警報已確認，也不自動交付。上位機暫停、要求人工核對，核對後取消本輪並保留紀錄，排除問題後明確建立新輪；不提供強制採用不確定結果或自動重測的操作。這接受人工介入的成本，以保留原始產品證據並避免跨輪誤取。

本決定修改顯示契約 1.1「人工停止不交付」的既有行為，不把人工停止改寫成正常完成；延續 ADR 0004 的待確認阻擋、ADR 0006 的不採用未知同輪結果，以及 ADR 0008 的結果放行與保存完整性分離。Log Solution 自己的來源候選處置仍依 ADR 0006；本決定的取消適用於橋接缺少同輪證據的中止／準備逾時路徑，不能將兩種情況混為一談。詳見 [本輪討論定稿](../refactoring/LOG_INSTRUMENT_DISCUSSION_2026-10-19.md)。

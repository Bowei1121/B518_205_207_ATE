# 分開監控經過時間、畫面心跳與開測證據

**Status: accepted — 2026-10-20（使用者A1～A16需求決策已確認，尚未實作與配對驗收）**

監控經過時間從本輪開始受理算到停止讀Log，包含來源準備、排除停止後人工確認及補存等待，並保存最後耗時；另外以全狀態持續更新的四格16態黑白心跳，每0.5秒變化一次，讓橋接比對影像變化。選擇獨立心跳而不以計時是否增加代表App活性，因為完成後計時必須停住，但畫面仍須可被觀察。

計時變化可以作本次開始流程已受理的輔助證據，不取代監控就緒、可信ATE活動與結果可交付規則，延續ADR0010／0011。狀態與心跳放同列且狀態可左移，接受顯示契約與橋接需配對更新的成本；相鄰不免除各自可讀性檢查。橋接由使用者與Claude另行修改，需求、量測與驗收必須分開記錄，不能將交接稿當已部署契約。

詳細需求及待量測事項見[App規格](../refactoring/LOG_SOLUTION_IMPROVEMENT_SPEC_2026-10-20.md)與[Claude交接稿](../refactoring/LOG_TIMER_HEARTBEAT_CLAUDE_HANDOFF_2026-10-20.md)。

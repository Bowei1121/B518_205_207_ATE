## 驗收條件

- [ ] 容量 4、6、10、12、20 的受控樣本中，有效位置及映射正確；一至二十的合法容量邊界受驗證。
- [ ] 容量十以內一排十格，十一至二十兩排各十格；第二排對應十一至二十。
- [ ] 容量外固定黑色；容量內 WAITING、NOTEST 等不得以容量外黑色代替。
- [ ] 來源編號與顯示位置不同、輸入順序改變時仍依配置映射，不用排序或固定 Thread 加一。
- [ ] 二十筆明細可捲動，色帶保持頂部固定，高對比與所需字體可讀。
- [ ] 平台能力不相容配置被指出；解析器未支援的容量不能僅靠 UI 填值宣稱支援。

## 驗證方式

受控資料與 Tk 可見布局驗證；平台可支援能力與樣本容量分開記錄。

**規格驗收對照：**AC-04、AC-05、AC-22（色帶／捲動部分）

## 保留決策、待確認事項與限制

容量不等於本輪投入數量；真實四通道儀器不能由配置變成二十通道。定位點及黑白標記接續 12。

所有行為測試須依 01 的接口確認結果落實；本次批准任務清單不代表測試接口已獲批准。未知同輪來源能否人工採用仍由 18 決定，任何本票的已完成部分都不能抵銷該未決分支。

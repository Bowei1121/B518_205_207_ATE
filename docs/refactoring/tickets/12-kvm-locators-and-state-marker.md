## 驗收條件

- [ ] 四種標記固定、不閃爍，有可驗證像素幾何、方向及辨識容差契約。
- [ ] 捲動二十筆、顯示衝突及警報時，色帶、定位點與標記均固定可見，不被確認窗口遮住。
- [ ] 開始新輪不出現上一輪完成標記搭配新輪初始化色帶的可取用畫面。
- [ ] 待確認、完成及人工停止的標記與結果放行一致；不以執行緒停止直接判完成。
- [ ] 高對比、快捷鍵、結果前景顯示及非持續置頂仍正常，新窗口尺寸不裁切頂部。

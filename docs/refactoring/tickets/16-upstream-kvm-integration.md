## 驗收條件

- [ ] 上位機程式、負責者、部署流程及可用 KVM 環境被定位並有紀錄。
- [ ] 各容量格位與容量外黑格辨識一致，四種標記在實際或受控 KVM 畫面可辨識。
- [ ] 確認窗口及警報期間不誤判完成，待確認暫停；未知或失真畫面不宣稱完成。
- [ ] 只在可靠完成標記取用同輪結果，新輪切換不誤取上一輪完成狀態。
- [ ] 事後異常不自動重做已完成動作，App 與上位機組合驗收有畫面、狀態及行為證據。
- [ ] 部署全面採新排列，不保留舊七格生產相容模式。

## 驗證方式

以不同容量、監控中、確認中、正常完成、整輪逾時與失真畫面驗證共同取用契約。

**規格驗收對照：**AC-17（上位機暫停）、AC-23～AC-25

## 保留決策、待確認事項與限制

外部前置：取得上位機程式與部署權責、KVM 環境。定位工作可先做，取得資源且 12 完成後才能整合；不能以 App 畫面代替上位機行為。

所有行為測試須依 01 的接口確認結果落實；本次批准任務清單不代表測試接口已獲批准。未知同輪來源能否人工採用仍由 18 決定，任何本票的已完成部分都不能抵銷該未決分支。

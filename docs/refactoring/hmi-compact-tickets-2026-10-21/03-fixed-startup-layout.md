# HC3：依螢幕決定固定高度與操作位置

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

App 啟動時依螢幕決定一次高度，此後選配置、換語言、通道增減與狀態改變都不移動表格可視區、開始按鈕、狀態及計時；通道少就在表格內留白。

父規格使用情境：1, 2, 3, 4, 13, 14, 15, 16, 17, 18, 32, 40。驗收情境：T01, T02, T03, T06, T08, T18。

## Acceptance criteria

- [ ] 依可用螢幕區域與實際字體／控制項需求決定一次高度，計算不依初始容量；相同設備與顯示條件重開位置穩定。沿用固定寬度並禁止手動拉伸。
- [ ] 考慮視窗裝飾與系統保留區，交付正常及較小支援螢幕的尺寸與適用條件，必要操作完整可見，不縮字或裁切達成。
- [ ] 容量 1、10、11、20、中英文與長狀態下，表格可視區、開始按鈕、狀態及計時幾何不變，上方結果色帶列數不間接推動它們。
- [ ] 表格內少量通道的未使用區顯示背景、不虛構 Slot；完整列數由固定可視區及 HC2 列高決定，放不下仍能捲動到底。
- [ ] 表格外框到開始按鈕只留小間距；交付相同條件改版前後的間距及高度量測，多餘間距朝減半目標縮減，表格內留白不混算。
- [ ] 紅字提示區預留固定占位並驗證可容納中英文與件數；實際閃爍由 HC4 交付。本票已有實際 App 可驗證的固定布局成果。
- [ ] 計時超過 99 分鐘仍完整顯示且不被長狀態遮住；原固定定位點、KVM 排列及容量顏色規則不變。

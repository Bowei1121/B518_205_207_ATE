# HC1：鈴鐺收納異常操作與一致件數

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

操作員可從鈴鐺查看啟動異常與待取消輪次並完成原有處理；主頁移除兩個異常處理按鈕及占位，鈴鐺件數包含所有適用的獨立待處理事項。

父規格使用情境：19, 20, 21, 22, 23, 24, 26, 27, 29, 33, 43。驗收情境：T09, T10, T11, T13, T15, T20。

## Acceptance criteria

- [ ] 鈴鐺同時支援無輪次啟動失敗與已受理輪次失敗，顯示原因、解除操作及停用原因；原主頁兩按鈕不再占位。
- [ ] 準備中停止及逾時路徑可從鈴鐺明確取消；拒絕確認不改輪次，接受才放棄交付並保留結果、原因及處置紀錄。
- [ ] 沿用既有開始鎖定與解除條件，不自動重試、開測或建立新輪，也不繞過必要警報確認與衝突處理。
- [ ] 鈴鐺件數涵蓋啟動異常、待取消輪次、未確認警報及保存／封存失敗；同一事項多入口不重複計數，不同獨立問題或輪次不遺漏。
- [ ] 零事項仍可開啟；查看、關閉、切分頁或語言不算解決。結果衝突維持原警告入口及獨立計數。
- [ ] 真 App 展示失敗→鈴鐺處理→明確新輪，以及保存後重新讀取紀錄；證明搬移未丟失或重複寫入證據。新入口有中英文操作說明，供 HC5 完成整體白話檢視。

## Blocked by

# HC7：新版本機幾何量測與 KVM 模板交接

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

橋接維護者可取得改版後實測幾何、計時裁切區與相容性說明，依各顯示條件建立模板，不再誤用舊版座標。

父規格使用情境：17, 18, 40, 41, 42, 45。驗收情境：T21。

## Acceptance criteria

- [ ] 沿用本機 Tk／原生影像矩陣，量測容量 1、10、11、20、中英文、雙縮放及實際支援高度下的布局。
- [ ] 交付開始、狀態、計時、提示、固定定位點、結果色帶及獨立心跳幾何，計時包含一般及長分鐘範圍，標註座標所屬影像與顯示條件。
- [ ] 核對通知有無與閃爍亮暗不推動計時或辨識區，不以紅字或計時變化替代獨立心跳與既有開測證據。
- [ ] 以現有 App 端本機契約 1.3 為基準，交付實際相容性判斷；如不相容依既有版本規則更新，不能沿用舊 ROI 冒充新模板。
- [ ] 產出可供橋接所屬專案配對的樣本與交接說明，不修改橋接程式、遠端命令或 ATE 控制。
- [ ] 本機截圖與 Tk 單位只標記為本機驗收；真實接收影像的像素、縮放與壓縮驗收留給 HC8，不宣稱尚未量測的遠端結果。

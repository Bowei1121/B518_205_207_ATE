# HC6：待確認、歷史與診斷的白話雙語提示

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

操作員在待確認、歷史查詢及診斷視窗查看按鈕時，可理解操作及不能按的原因，切語言後仍保有目前的閱讀與操作內容。

父規格使用情境：35, 36, 37, 38, 39, 40, 44。驗收情境：T16, T17, T19。

## Acceptance criteria

- [ ] 清點待確認、歷史查詢、診斷及其現有子視窗按鈕，交付提示／停用原因覆蓋清單與等義繁中英文文案。
- [ ] 維持既有來源證據、結果裁決、查詢、分頁、重試與紀錄語意；白話提示不誤導為自動採用、強制交付或刪除證據。
- [ ] 滑鼠停留、鍵盤焦點及停用原因提示皆可實際查看，不因查看觸發動作或修改資料。
- [ ] 切換語言原地更新提示，保留既有草稿、固定查詢結果、選取及閱讀位置，不以重開視窗代替刷新。
- [ ] 提示不遮住必要操作或辨識區；離開、關閉及重開視窗無殘留提示或失效回呼。
- [ ] 沿用各視窗既有真 App 驗收，涵蓋可用／停用、中英文及關窗；本票與 HC5 分工按使用情境，不另建第二套提示機制。

## Blocked by

None (can start immediately)

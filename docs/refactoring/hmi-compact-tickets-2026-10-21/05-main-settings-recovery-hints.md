# HC5：主頁、設定與鈴鐺的白話雙語提示

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

操作員在主畫面、設定與通知恢復中心查看按鈕時，可用繁中或英文理解按下的效果，以及目前為什麼不能按。

父規格使用情境：24, 34, 35, 36, 37, 38, 39, 40。驗收情境：T16, T17。

## Acceptance criteria

- [ ] 清點主畫面、設定、通知恢復及其現有子視窗按鈕，交付提示／停用原因覆蓋清單與中英文文案；包含 HC1 搬移後的兩個入口。
- [ ] 文案先說按下做什麼，再說必要結果或停用原因；不只用復位、封存等術語代替說明，也不擴大成全介面重新命名。
- [ ] 明確區分開始監控與啟動測試設備、解除異常與自動重試、取消輪次與刪除紀錄，以及停止與取消。
- [ ] 實際滑鼠停留與鍵盤焦點可顯示說明，停用按鈕仍可查看原因，查看不執行操作。
- [ ] 已開視窗與提示依目前語言更新，離開控制項或關窗不留殘影與失效回呼；提示不遮住必要操作與辨識區。
- [ ] 沿用既有提示驗收入口，逐類展示可用／停用及中英文操作，不只檢查資源字串存在。

# HC2：縮小通道列高、黑色格線與完整捲動

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

操作員可在相同表格空間讀到更多完整通道，以黑色橫直線清楚分隔；空間不足時仍可捲動到最後一列。

父規格使用情境：5, 6, 7, 8, 9, 10, 11, 12。驗收情境：T04, T05, T07。

## Acceptance criteria

- [ ] 保留既有主畫面字體大小，依字體實測縮小上下留白；所有通道使用一致列高，狀態與 SN 顯示語意不變。
- [ ] 取消文字表格的全部十列限制；以足夠的可視高度實際顯示超過十列，不改上方 KVM 每排十格與最多二十通道的規則。
- [ ] 不足顯示全部通道時，捲動可到最後完整列，不以裁切列代替完整列；全部可見時捲軸保留原位且停用。
- [ ] 內部橫線與直線為清楚黑色，狀態背景色與文字可讀性維持；不同縮放均交付實際截圖與列高／線寬量測。
- [ ] 沿用真 App 表格驗收，更新舊十列上限斷言，涵蓋 1、10、11、20 通道及中英文；本票驗收表格行為，不凍結尚待 HC3 決定的整體視窗幾何。

## Blocked by

None (can start immediately)

## Acceptance criteria

- [ ] 在整合後確切提交執行父規格 T01～T22，逐一對照全部 45 個使用情境；沿用各票證據但補足互動情境，不以單票自查冒充完整整合驗收。
- [ ] 真 App 串接啟動失敗解除、準備中停止／逾時後取消、警報處理、保存失敗重試與重讀紀錄，確認新輪、舊證據及交付條件保持正確。
- [ ] 核對主頁與全部子視窗的中英文提示覆蓋、停用原因及生命週期，含紅字閃爍時切語言、長狀態／計時與關窗。
- [ ] 依 HC7 交接，以真實 JetKVM 接收影像及更新後模板驗證裁切、縮放／壓縮可讀性、計時、狀態、結果與獨立心跳；橋接實作仍由其所屬專案處理。
- [ ] 無設備或配對條件時，明列 T22 及相關硬體項目待驗、缺口與所需條件；不得打勾、關票或把本機證據當成遠端驗收。
- [ ] 記錄版本、平台、Python、顯示條件、原始結果與 skip；適用平台的既有必要回歸通過，未驗證的平台不宣稱通過。
- [ ] 依既有同 PR 修正及獨立審查流程交付驗收結果；本票不自動關閉或改寫父議題 #105。

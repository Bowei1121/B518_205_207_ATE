# HC4：待處理事項紅字閃爍與生命週期

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/105

## What to build

鈴鐺有待處理事項時，主畫面以相同件數顯示每秒亮暗的紅字；實際處理完才停止，開啟鈴鐺或改語言都不會消除提醒。

父規格使用情境：25, 26, 28, 29, 30, 31, 32, 42, 44。驗收情境：T11, T12, T13, T14, T15, T18, T19。

## Acceptance criteria

- [ ] 使用 HC1 的同一份待處理清單取得件數；繁中顯示「有 N 件事需要處理，請點鈴鐺」，英文意思一致；結果衝突不混入。
- [ ] 每秒切換紅字亮暗一次，使用 HC3 的固定提示區，不因亮暗、出現或消失改變其他元件幾何。
- [ ] 開啟／關閉中心、切分頁及語言均不清零或停閃；部分完成更新件數、失敗保留、全部完成才隱藏文字且保留占位，新事項可再次啟動提醒。
- [ ] 閃爍與監控經過時間及獨立 KVM 心跳互不影響，通知更新不產生輪次永久紀錄。
- [ ] 真 App 覆蓋多種並存事項、長件數、中英文、長計時及長狀態；關閉／重開中心不造成重複閃爍，App 關閉後無失效回呼。
- [ ] 原保存失敗、重試及取消關閉流程保持可操作；閃爍不能被當成 App 心跳或 ATE 開測證據。

# ST1 / #69 — 真正 App Slot viewport 驗收

基準：`612c6d0`，功能分支 `codex/st1-slot-scroll`；實作期間同步整合文件 tip `e245f6c`。

## 行為

- Slot 最多十個完整 46px 資料列；保留原 14pt 字體、黑框、欄位及狀態色。
- 實際可用高度扣除頂列、機型、KVM、欄名、主要操作等實際請求高度後，取可放入的完整列數；主要操作先保留空間。
- 資料外的空白使用主頁淺灰；垂直捲軸固定保留欄位。以 Canvas 真正可視範圍決定啟用，全部可見時淺灰停用。
- 停用捲軸箭頭／拖動無法移動資料；啟用時透過真正捲軸箭頭操作至末端，末列完整可讀。機型容量下降後回到合法位置，欄寬不跳動。
- 保留既有 macOS `resizable`／WM bounds 程式化尺寸修正與 KVM 契約。

## TDD 與入口

使用 `mattpocock-skills:tdd`。已確認 seam：真正 `B518LogSolutionApp`／Tk 視窗與既有公開選單、機型選取、捲軸操作。配置是暫存測試 fixture，不讀取原工作樹暫稿。

第一個紅燈在原程式可重現：容量 1 的 `rows_scrollbar.winfo_ismapped()` 為 0（原程式 `pack_forget`），未保留捲軸欄位。實作後再依真正視窗幾何測試整個容量／高度矩陣。

`tests/test_slot_toolbar_st1.py` 會以捲軸箭頭按下／釋放事件持續捲至 `yview[1] == 1.0`，並以每列實際像素 bounds 檢查末列完整；不只檢查 disabled、樣式或 widget 存在。停用時另操作拖移，確保沒有位置變化。JSON 保存實際箭頭點擊數。

開發中曾用「最多 40 次箭頭」當循環上限；20 容量／650 高的 188px viewport 每步約 18px，需要約 42 次，40 次只到 `yview[1]=0.985`。該次測試失敗沒有當成通過；最終版逐次捲到真正末端（保留 200 次防失控上限）。

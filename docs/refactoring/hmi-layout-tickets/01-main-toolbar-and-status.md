# HM1：主頁圖示頂列與操作區狀態

## Parent

[規格 #47](https://github.com/Bowei1121/B518_205_207_ATE/issues/47)。

## What to build

主頁維持376px，頂列左側設定圖示＋Foxlink Logo，右側待確認數字／整輪警報／語言圖示；監控狀態移至開始停止附近，主標題隨配置更新。

## Acceptance criteria

- [ ] 依選定操作區原型完成固定格位、純圖示及Logo等比顯示，移除B518 LOG與重複Log Monitoring，保留專案／機型選擇及全部原功能。
- [ ] 待確認數直接取當輪既有事項清單，不按位置去重、不混整輪警報；零／一／多位數與啟用／停用均不推移按鈕，不截掉事項資訊。
- [ ] 語言地球menu保留母語名稱、目前選取與持久偏好；監控／待確認可切語言，關閉保存沿用既有暫停切換。
- [ ] 圖示有目前語言提示、可辨識操作名稱、鍵盤展開／選取／Escape；設定、裁決、警報仍走原入口，不新增聲音或自動確認。
- [ ] Logo正常／缺失／損壞均保持固定區，失敗留白不恢復替代字或彈窗；來源原圖不改，資產來源與既有打包讀取路徑有檢查。
- [ ] 監控文字在開始停止附近固定欄，保留各狀態與必要數量；標題為專案、機型、ATE Log Solution及集中版本，切語言不覆回舊標題，不自行遞增版本號。
- [ ] 真Tk比對376px雙語格位、長數字與狀態、圖示可操作；同容量KVM整區位置、內部幾何／色塊／標記不變，不把HTML像素直接當Tk驗收。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

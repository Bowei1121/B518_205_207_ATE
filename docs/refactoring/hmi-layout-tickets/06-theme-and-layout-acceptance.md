# HM6：全App淺色一致性與整體驗收

## Parent

[規格 #47](https://github.com/Bowei1121/B518_205_207_ATE/issues/47)。

## What to build

整合所有App視窗的固定淺色、雙語布局及圖示可操作性，完成Logo部署資產與KVM契約對照，交付整體一致HMI。

## Acceptance criteria

- [ ] 45項故事與全部畫面矩陣逐項對照最終程式，涵蓋設定各頁、覆核、警報、歷史／異常、診斷、保存及一般提示，不只主頁。
- [ ] 收尾共同主題／樣式，App自有一般／停用／選取／焦點狀態均維持淺色；在可重現系統深淺桌面環境驗證不跟隨，不改全機外觀。
- [ ] 同尺寸、字型／DPI、容量及狀態切語言，真正元件bounds一致且長內容可讀；保留原有視窗調整／拖曳／捲動與輸入選取。
- [ ] 純圖示停留／焦點說明、鍵盤、menu展開選取／Escape與零／多位數狀態完整可用；不能以原型、mock widget或圖片相似度代替實際操作。
- [ ] 同容量與視窗條件對照KVM整區位置、幾何／色塊／定位與狀態標記解碼，一／兩排及未使用黑格與待確認不放行契約不變。
- [ ] Logo來源及既有正式打包資產路徑可驗證，缺失／損壞留白不跳位；主／子標題與集中版本一致，原型來源9637913作決策對照不合入產品。
- [ ] 完成必要相關完整回歸與真正桌面驗證，功能不因示意省略而消失；不預設跑數小時216萬事件流程，工廠／實體設備／部署限制分開記錄。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

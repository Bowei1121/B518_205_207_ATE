# HM4：歷史與診斷視窗固定雙語布局

## Parent

[規格 #47](https://github.com/Bowei1121/B518_205_207_ATE/issues/47)。

## What to build

歷史條件、事件／異常列表、詳細及診斷畫面切語言位置穩定，保留查詢與閱讀狀態；不改查詢演算法。

## Acceptance criteria

- [ ] 視窗標題符合當前功能與語言、不加專案名；涵蓋正常事件、來源異常與App診斷入口。
- [ ] 條件標籤、頁面控制、列表、詳細及異常操作固定預留空間，長英文／原文不撐動按鈕，原有捲動可用。
- [ ] 切語言保留日期草稿、已提交條件、查詢世代、頁碼、選取及閱讀位置，不自動查詢、重掃、重建索引或保存原文。
- [ ] 一般唯讀與診斷文字同底色細黑框，可操作日期／選擇欄維持白底；狀態顏色保留且焦點／停用／選取可辨識。
- [ ] 等待、取消、部分結果、索引降級與故障重試等已存在狀態都可讀，不能因原型省略而隱藏實際功能。
- [ ] 真Tk混合真實暫存紀錄，實際操作日期、分頁／異常／詳細與切語言，保存中英bounds／畫面、原始bytes及狀態不變證據。
- [ ] 不依賴QP組全部完成；若已整合新查詢狀態，僅依其公開狀態呈現並補對應布局，不另造資料或版本規則。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

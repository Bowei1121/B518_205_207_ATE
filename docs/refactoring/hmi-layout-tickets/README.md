## 執行與交付界線

HM1–HM5沒有真正功能依賴，均可先開始；但多票會修改相同主App與翻譯／樣式，建議依序整合或以隔離checkout工作並逐次回歸，不為共用檔案衝突添加假的原生阻擋。HM6依五票收尾全App主題、資產及幾何驗收。

每票即完成自己的實際視窗、雙語固定布局、局部淺色／唯讀樣式及必要回歸，不能把所有樣式或鍵盤可操作性丟給HM6。共同樣式更動須檢查現有畫面。主頁固定376px、選定操作區狀態；不直接把HTML原型搬入產品。

不依賴QP組全部完成。歷史視窗使用基準既有公開狀態；如已整合QP新狀態再補畫面對照，不另造查詢演算法。KVM整區位置、幾何及色塊不得因標題／工具列改動平移。

每票必要開發、真正桌面與相關回歸通過可合併，最後一票驗收全規格。工廠／實體設備／正式部署另追蹤，不阻擋開發合併；未驗收項目不能冒充通過。建立票件不是程式實作完成。

# HM3：衝突與警報視窗固定雙語布局

## Parent

[規格 #47](https://github.com/Bowei1121/B518_205_207_ATE/issues/47)。

## What to build

衝突精簡／詳細區與整輪警報在雙語切換後不移位，保留候選選取、拖曳分隔與閱讀位置；人工決定與確認規則不變。

## Acceptance criteria

- [ ] 衝突與警報標題符合功能／語言，不加專案名；已符合的標題不無故改名或改變錯誤語意。
- [ ] 精簡對照、詳細原文、候選列表與按鈕預留雙語空間，相同尺寸狀態切語言bounds一致，不遮擋或裁掉操作。
- [ ] 保留既有結果／SN／時間／來源比較、紅色粗體差異、同名異路徑提示及捲動／可調分隔，不能以主題一致刪掉辨識語意。
- [ ] 切語言不改候選選取、不清原始內容、不自動裁決或確認警報；保留原裁決、逾時確認、未確認不放行規則。
- [ ] 一般唯讀文字同背景黑框，具結果或警報語意顏色保留；本票畫面的一般／停用／焦點／選取皆維持App淺色。
- [ ] 真Tk用長英文、多候選、長路徑／診斷與不同警報狀態實際操作，記錄雙語bounds／截圖與閱讀位置，不只比對字串。
- [ ] 保持警報／覆核視窗對KVM標記的防遮擋契約，相關回歸確認無原始資料、序號或監控結果改動。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

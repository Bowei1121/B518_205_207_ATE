# HM5：保存關閉與一般提示視窗固定雙語布局

## Parent

[規格 #47](https://github.com/Bowei1121/B518_205_207_ATE/issues/47)。

## What to build

保存、失敗、重試、取消關閉與一般App提示在雙語下保持穩定布局和功能標題，保留完整保存才關閉的契約。

## Acceptance criteria

- [ ] App自有保存及一般提示標題依功能／語言命名，不帶專案；長錯誤說明、原文及診斷可讀，不冒充系統原生選檔器。
- [ ] 相同視窗尺寸／狀態下切語言bounds穩定，內容在預留區換行／捲動，不推移確認、重試或取消操作。
- [ ] 保留失敗原因、目前保存進度與人工入口，不改提示時機、按鈕效果或警報確認；切語言不自動確認／取消。
- [ ] 保存成功才關閉，失敗可重試及取消關閉；關閉保存期間語言切換限制沿用既有規則，不為布局測試繞過。
- [ ] 一般唯讀原文同底色細黑框，必要狀態色保留；本票App提示的一般／停用／焦點／選取均維持淺色與可操作性。
- [ ] 真正Tk與真實暫存保存／受控故障驗證保存、重試、取消關閉、模態焦點與Escape等適用入口，記錄中英畫面及bounds。
- [ ] 相關回歸涵蓋多輪未保存、封存、語言通知與提示重開，不能只改樣式測試；不改原始保存／清理／監控政策。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

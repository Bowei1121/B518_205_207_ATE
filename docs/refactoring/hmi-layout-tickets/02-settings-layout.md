# HM2：設定視窗固定雙語布局

## Parent

[規格 #47](https://github.com/Bowei1121/B518_205_207_ATE/issues/47)。

## What to build

設定各頁繁中英文切換位置穩定，保留輸入與選擇；標題為設定／Setting，唯讀輸出同底色黑框，輸入欄位保留白底。

## Acceptance criteria

- [ ] 標題依語言為設定／Setting，不帶專案名；保留全部設定頁及配置、期限、匯入匯出等正式功能，不以原型示意刪減內容。
- [ ] 相同尺寸／字型環境與狀態切語言，標籤、欄位及按鈕bounds不因翻譯長短改變；預留中英文較大空間。
- [ ] 保留未送出輸入、選取、頁籤與閱讀位置，長路徑／說明可讀可捲動，不把按鈕推出畫面。
- [ ] 一般唯讀文字同主背景細黑框，編輯與可選擇欄位白底；readonly選單仍屬選擇入口，不誤當唯讀輸出。
- [ ] 本票設定畫面所有一般／停用／焦點／選取狀態採App淺色規則，保留必要錯誤語意，不改全機或系統原生選檔器。
- [ ] 真Tk實際操作期限、配置選擇／輸入及可用匯入匯出路徑，對照中英截圖與bounds；來源／偏好寫入僅透過原正式操作。
- [ ] 不新增獨立語言偏好、快取設定或平台，不改保存期限資格與原有驗證提示效果；共同樣式修改必須檢查現有畫面不退步。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

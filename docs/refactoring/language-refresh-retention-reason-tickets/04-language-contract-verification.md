## Acceptance criteria

- [ ] 盤點所有自有視窗與主畫面，確認沒有遺漏、雙重刷新、失效登記或長期平行流程；移除無呼叫者的舊串接。
- [ ] 不刪除正常輪次事件或資料變更所需的呈現能力，僅移除語言切換的重複路徑。
- [ ] 完成規格第一項全部九項驗收情境，涵蓋多視窗、草稿、衝突警報、查閱、生命週期、故障、最新語言重試、恢復與保存政策。
- [ ] 重複開關視窗與快速切語後，選取、輸入、閱讀、焦點及模態效果保持；失敗隔離與彙整提示正常，不持續自動重試。
- [ ] 檢查既有來源、事件及舊摘要 bytes 不改寫；合法新增的故障診斷與被保護紀錄分開驗證。
- [ ] 保留有意義的舊行為情境，移除失去價值的私有呼叫鏈測試；新增測試驗證可觀察行為。
- [ ] 完成必要檢查及適用回歸，記錄版本、命令、結果與限制，第一項可獨立交付；不宣稱 bundle／現場驗收完成。

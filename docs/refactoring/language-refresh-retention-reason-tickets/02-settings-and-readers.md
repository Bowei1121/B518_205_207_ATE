## What to build

設定、App 診斷與歷史視窗直接接收語言通知，就地更新標題、欄位及內容，保留草稿與閱讀狀態；其更新失敗可沿 L1 入口恢復。

## Acceptance criteria

- [x] 設定、App 診斷、歷史視窗接入已驗證通知契約，移除這些視窗的重複手動刷新，不牽動尚未遷移視窗。
- [x] 有效與無效草稿、尚未送出輸入及既有驗證狀態保持，不重新讀來源或自動送出設定。
- [x] 診斷與歷史事件選取、閱讀及捲動位置保持，標題及詳細內容使用目前語言；不重建視窗。
- [x] 由各種實際關閉入口解除自身登記，反覆重開、隱藏再顯示及更新時已銷毀均不留下失效接收者。
- [x] 任一視窗故意失敗時其他視窗仍更新，主畫面彙整與診斷可見；修復後重試用最新語言且不清草稿／選取。
- [x] 真正 Tk 驗證同時開窗快速切語、無效草稿、選取與閱讀、生命週期及重試；既存事件／摘要 bytes 保持，新增故障診斷另行驗證。
- [x] 原有設定操作、紀錄查閱與診斷保存效果保持，原生檔案選擇器依系統；相關既有測試通過並記錄實際結果。

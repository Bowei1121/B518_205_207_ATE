# QP3：500筆快取與閱讀優先載入

## Parent

[規格 #46](https://github.com/Bowei1121/B518_205_207_ATE/issues/46)。

## What to build

操作員跨越前五頁、往返較遠頁面或選取詳細時，系統優先滿足閱讀需求；只保留閱讀位置附近最多500筆列表，未備妥時保留原畫面並顯示載入中。

## Acceptance criteria

- [ ] 正常列表快取最多500筆，首批相容檢視也納入同一預算，不另保留永久500筆；遠頁淘汰後可從固定版本重新載入。
- [ ] 頁面與詳細需求優先於後續預先處理；有限批次／緩衝與工作數，不以無限制worker或全量原始物件駐留換速度。
- [ ] 要求頁尚未備妥時保留目前頁面／有效選取，清楚顯示載入中；可靠頁面取得後才更換顯示頁碼，不誤報沒有資料。
- [ ] 跨第5／6頁、回翻及快速連續要求不同頁時，身分、排序、總數與版本一致；舊頁面或詳細晚到不搶走目前顯示。
- [ ] 詳細按選取取得，列表淘汰不影響固定原文；診斷、索引游標與背景緩衝成本分開揭露且可回收。
- [ ] 真Tk慢讀下翻頁、詳細、切語言、重查與取消可操作，切語言不全量掃描、不丟閱讀位置；以公開入口及真實磁碟驗證。
- [ ] 以超過500筆固定集合量測快取窗口、複製量與記憶體，反覆往返不持續成長；不把整份原始資料載入再切頁。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

# QP1：重查重用固定原文

## Parent

[規格 #46](https://github.com/Bowei1121/B518_205_207_ATE/issues/46)。

## What to build

讓實際App重複查詢重用未變更的事件內容，避免每次複製全部原文；各次結果仍是固定版本，來源清理或替換後原文保持可讀。本票先保留既有整批完成的發布方式，為後續首批發布提供可用基礎。

## Acceptance criteria

- [ ] 從正式查詢入口取得日期、來源優先、身分、數字序號排序及原文與安全原檔基準一致的結果；舊相容入口仍可使用，不新增Tk端查詢規則。
- [ ] 重查與全新查詢實例能重用有效索引及未變更內容，只更新新增／變更部分；實測完整內容複製bytes／筆數下降，不以零原檔解析冒充零內容複製。
- [ ] 各查詢持有可信固定版本，共用內容更新不能原地覆寫正在閱讀的結果；來源刪除／替換後，未曾選取的後頁詳細也保留原文。
- [ ] 採可驗證的漸進遷移，不變更原始保存格式、日期／DST政策，不把路徑引用當完整內容替代，也不全面載入原始物件至記憶體。
- [ ] 建立查詢引用／釋放責任，替換與關閉可安全回收無引用資料，仍有效內容不提前刪除；正常保存及期限清理不等待查詢。
- [ ] 以公開查詢、真實暫存來源／索引、全新實例及正式保存／清理入口測試版本隔離；真Tk證明目前App可讀與可關閉、來源bytes不因查詢改寫。
- [ ] 固定修改前基準並記錄來源同步、結果內容準備及衍生大小的可重現成本；此票不提前宣稱500筆預載或整份規格完成。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

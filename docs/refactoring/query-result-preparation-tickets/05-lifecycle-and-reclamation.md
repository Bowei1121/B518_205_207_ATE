# QP5：重查取消與共用資料回收整合

## Parent

[規格 #46](https://github.com/Bowei1121/B518_205_207_ATE/issues/46)。

## What to build

整合新批次、快取及重試的生命週期，讓最新查詢勝出；取消、替換或關閉後停止舊工作並回收無引用資料，同時保護仍在閱讀的版本與正常保存清理。

## Acceptance criteria

- [ ] 對總數、首批、後續批次、頁面、詳細、進度與錯誤驗證完整世代隔離，多次重查亂序完成仍只發布最新有效要求。
- [ ] 首批前後取消狀態及保留內容一致；關閉重開不接受舊回傳，不新增自動重查或無限制背景工作。
- [ ] 新結果替換／視窗關閉／App退出回收無引用的查詢與過時共用內容，仍引用的內容不被刪；有效可重用索引保留。
- [ ] 重啟可重用有效索引，不恢復上個查詢視窗／列表快取，不新增操作員快取設定。
- [ ] 正式來源追加、替換與期限清理期間，首批和後頁原文保持固定；不因查詢延後合法清理，不因GC改原始保存資格。
- [ ] 真Tk、正式保存／清理公開入口與全新讀取器驗證慢讀、取消、重試、語言切換及正常關閉；App保存不等待失效查詢。
- [ ] 反覆查詢、故障恢復、關閉重開後worker、引用、暫存與記憶體不持續累積；涵蓋索引降級及未完整保存／待確認保護回歸。

- [ ] 本票必要功能測試、真正桌面與相關回歸通過後可合併；維持既有行為保護，不把後票完整驗收提前當本票前提。工廠驗收獨立追蹤，不阻擋合併；大型補驗需有具體風險理由，不默認每票數小時重跑。

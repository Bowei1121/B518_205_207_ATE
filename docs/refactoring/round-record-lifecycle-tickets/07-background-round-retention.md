# T7：背景清理到期整輪紀錄，保留摘要並可恢復失敗

## Parent

Part of [規格 Issue #1](https://github.com/Bowei1121/B518_205_207_ATE/issues/1)。依 ADR 0007／0008 與已確認拆票方案實作。

## What to build

App 依工程師設定，於啟動後、持續開啟每 24 小時及設定修改後安排背景清理。只刪除到期、已結束且完整保存的整輪紀錄，UI 不中斷；留下持久摘要，失敗下次安全重試。此票才啟用自動刪除，必要保護與故障恢復同票完成。

## Acceptance criteria

- [x] 封存時間加目前有效保存天數判定到期，涵蓋期限前、恰到期限與期限後；新期限適用所有可信既有輪次。（期限前／恰到期限／366 天、縮短設定及每日排程已有隔離磁碟測試；待最終複審。）
- [ ] 同輪多目錄聚合後整輪清理，刪除前重新檢查完整性及保護狀態，不刪活躍、準備中、待確認、寫入中、保存失敗、未知、損壞或缺少可信封存時間資料。
- [ ] 刪除限 App 管理的輪次資料；配置、偏好、人工匯出、來源 Log 及符號連結外部資料保持完整。
- [ ] 背景工作合併多個觸發且不重疊；關閉保存期間不啟動新清理，既有工作與關閉及新增保存安全協調，UI 保持可操作。
- [x] 摘要記錄時間、使用期限、輪次、刪除／跳過／失敗及原因；被刪資料消失後仍能查看摘要，摘要寫入失敗可見且不虛報成功。（隔離磁碟、新 Coordinator 重讀及初始摘要故障測試通過。）
- [x] 單輪失敗不停止其他安全候選；多目錄部分刪除失敗保留可恢復進度，下次不誤判剩餘資料或重複虛報整輪完成。（損壞輪次與安全候選並行、部分刪除故障及新 Coordinator 續作測試通過；待最終複審。）
- [ ] 以公開協調入口、注入時鐘、真實暫存檔及實際 Tk 驗證排程、設定變更、完整清理、保護、保存競爭、關閉競爭、故障恢復及摘要。
- [ ] 全部規格驗收覆蓋查核完成，新舊資料讀取及產品／KVM 契約不變；受控驗證不冒充現場設備驗收。

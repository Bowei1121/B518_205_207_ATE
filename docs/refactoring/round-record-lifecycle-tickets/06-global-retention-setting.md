# T6：工程師可持久設定全域輪次保存天數

## Parent

Part of [規格 Issue #1](https://github.com/Bowei1121/B518_205_207_ATE/issues/1)。依 ADR 0007／0008 與已確認拆票方案實作。

## What to build

工程師在 App 設定畫面設定全域保存天數，預設 365 天，可改為 180 天或其他正整數。設定跨重啟保存，縮短期限時提示既有紀錄可能到期；此票不提前啟用資料刪除。

## Acceptance criteria

- [ ] 設定屬全域 App，不綁單一測試配置；無既有值預設 365。
- [ ] 接受 180 及其他正整數，拒絕空白、非整數、零、負數；無效值或保存失敗時維持原有效設定並呈現錯誤。
- [ ] 重啟、其他配置保存及配置匯入匯出不意外遺失或覆寫保存天數。
- [ ] 設定畫面提示縮短期限會讓既有可清理紀錄到期，下一次背景清理生效；天數按完整 24 小時定義。
- [ ] 真正 Tk 設定、驗證、錯誤及持久讀寫測試通過；本票不刪除任何輪次資料。

## Blocked by

None (can start immediately).

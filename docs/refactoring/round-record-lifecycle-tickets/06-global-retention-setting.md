# T6：工程師可持久設定全域輪次保存天數

## Parent

Part of [規格 Issue #1](https://github.com/Bowei1121/B518_205_207_ATE/issues/1)。依 ADR 0007／0008 與已確認拆票方案實作。

## What to build

工程師在 App 設定畫面設定全域保存天數，預設 365 天，可改為 180 天或其他正整數。設定跨重啟保存，縮短期限時提示既有紀錄可能到期；此票不提前啟用資料刪除。

## Acceptance criteria

- [x] 設定屬全域 App，不綁單一測試配置；無既有值預設 365。（無偏好檔及舊格式缺欄位的新讀取器測試皆確認預設，見[驗收紀錄](../evidence/ticket-06/local-validation.md)。）
- [x] 接受 180 及其他正整數，拒絕空白、非整數、零、負數；無效值或保存失敗時維持原有效設定並呈現錯誤。（Store 與真正 Tk 測試包含 180、730、無效輸入及原子替換失敗。）
- [x] 重啟、其他配置保存及配置匯入匯出不意外遺失或覆寫保存天數。（使用全新 Store 重新讀取，並由真正 Tk 配置保存／匯入、配置匯出測試確認全域欄位不進入配置文件。）
- [x] 設定畫面提示縮短期限會讓既有可清理紀錄到期，下一次背景清理生效；天數按完整 24 小時定義。（真正 Tk 設定分頁文字及縮短期限結果已驗證。）
- [x] 真正 Tk 設定、驗證、錯誤及持久讀寫測試通過；本票不刪除任何輪次資料。（檔案清單與 Session bytes 在設定操作前後相同；本票未加入清理或刪除程式。）

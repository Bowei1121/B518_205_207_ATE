# 人工衝突彈窗精簡資訊討論

日期：2026-10-07（Asia/Taipei）。使用 grill-with-docs 的 grilling 與 domain-modeling 流程；此文件記錄討論，不代表產品實作完成。

## 使用者已指定的方向

- 左側維持衝突選單。
- 右上新增精簡資訊欄位，內容比較衝突前後資訊。
- 右下維持原有詳細資訊，提供較完整內容。
- 目的是減少人工覆核時資訊過多、過雜，讓操作員先掌握差異，再按需要閱讀細節。

## 待釐清

- 精簡欄位的最低資訊與資料缺失表示。
- 前後對照及差異標示方式。
- 精簡與詳細區域的空間、操作按鈕及更新行為。

保留既有逐項人工覆核、停止收集與放行分離，以及未知同輪來源不得人工採用的政策。待討論形成共識後才修改產品程式；本次 UI 呈現方向可逆，尚無需要新增 ADR 的架構取捨。

# C2：差異兩側紅色粗體並辨識同名不同來源

## Parent

Part of GitHub 規格 Issue #9。草案，待使用者確認後發布。

## What to build

操作員在四項對照中直接辨識變更：不同欄位的原結果與新候選兩側值皆紅色粗體，相同值一般文字。同名但不同路徑以簡短、足以區分的目錄提示顯示來源差異，完整證據仍可在下方查閱。

## Acceptance criteria

- [ ] 結果、SN、來源時間及來源檔名獨立比較，不同值兩側紅色粗體，相同值一般文字；顏色不表示採用建議或 PASS／FAIL 偏好。
- [ ] 切換選取清除前項差異樣式；一側缺少值標示差異，兩側皆缺少顯示相同未知。
- [ ] 不同檔名顯示差異；同名不同路徑補足以區分的短目錄提示且兩側標紅，尾端目錄也同名時仍不造成假一致。
- [ ] 相同來源路徑的來源欄一般文字，原地更新造成的其他欄位差異仍突出；不把 basename 當唯一來源身分。
- [ ] 完整路徑與原識別保留在詳細區，長檔名或提示不遮蔽裁決操作，原最小尺寸仍可用。
- [ ] 使用受控平台來源及真正 Tk 驗證欄位值、兩側樣式、路徑提示、未知、拖曳後閱讀與切換後樣式重置。

# C1：衝突彈窗提供四項精簡對照與可拖曳詳細分區

## Parent

Part of GitHub 規格 Issue #9。草案，待使用者確認後發布。

## What to build

操作員可在右上閱讀固定四項原結果／新候選對照，在右下查閱原本全部細節。左側選單與底部按鈕位置維持；上下初始約 40%／60%，可拖曳調整。此票先交付基本對照，差異紅色粗體及同名來源消歧於 C2 完成。

## Acceptance criteria

- [ ] 精簡區固定結果、SN、來源時間、來源檔名順序，顯示項目／原結果／新候選標題及所選顯示位置。
- [ ] 精簡與詳細內容來自同一捕捉快照，來源檔案事後修改不改寫待裁決資料；不重讀來源、不改來源時間語意。
- [ ] 來源平常顯示檔名，完整路徑與原來源識別留在詳細區；缺少值顯示未知，不從識別碼或觀察時間猜測資料。
- [ ] 詳細區保留原全部內容，沒有因精簡欄位而刪除輪次、衝突及來源證據。
- [ ] 上下初始約 40%／60%、可拖曳調整，既有最小尺寸可操作，不新增持久比例設定或部署螢幕要求。
- [ ] 左側選取的一般切換能更新上下內容，底部保留原結果／採用新結果／關閉的效果維持，彈窗仍非模態。
- [ ] 真正 Tk 從受控衝突到顯示、拖曳及既有裁決操作驗證通過，其他位置仍可收集。

## Blocked by

None (can start immediately).

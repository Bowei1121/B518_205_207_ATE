## What to build

工程師能閱讀可見且穩定的背景清理摘要，無結果有明確提示，更新與換語言後仍保有合理閱讀位置。

## Acceptance criteria

- [ ] 先重現並記錄空白及跳動的桌面條件，區分已觀察的無條件重建行為與尚未證實的空白根因；不虛構已完成重現。
- [ ] 沒有清理結果時顯示明確本地化空狀態；有結果時摘要、失敗原因及必要原始診斷可閱讀，不留無法判斷狀態的空白。
- [ ] 內容及語言未變時不反覆重建；觀察多個既有定時更新週期，畫面及捲軸不跳動或閃爍，不以私有函式呼叫次數驗收。
- [ ] 內容或語言改變才更新，保留合理閱讀位置及仍有效的選取，內容縮短時位置調整合法，長摘要仍可捲動。
- [ ] 驗證無結果、有結果、長結果、更新、失敗、切語言及重新開關設定頁；若巢狀捲動或布局造成空白則修復實際原因，不只隱藏捲軸。
- [ ] 不強制新增特定捲軸自動隱藏策略；保留期限、清理資格、排程及紀錄保護政策不變。
- [ ] 提供真正 App 繁中／英文的重現、修復後內容與穩定閱讀證據，完成對應清理及語言行為回歸。

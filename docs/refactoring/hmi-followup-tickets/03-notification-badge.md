## Acceptance criteria

- [ ] 數量等於未確認整輪警報項目數，加上具有保存／封存異常的不同輪次數；同輪多錯誤去重，但同輪獨立警報仍另計。
- [ ] 一警報加兩輪保存異常顯示三；正常保存中、無異常的進行中未保存工作、⚠️ 待確認及 App 診斷異常不加入鈴鐺。
- [ ] 反覆開關視窗不清零；重試進行中與再次失敗保留尚未排除項目，部分修復但同輪仍有另一失敗時維持一筆，成功後正確減少。
- [ ] 計數依既有未處理狀態，不以日誌條數或未讀旗標計算；保留歷史錯誤證據但不讓已排除錯誤永久卡住數量。
- [ ] 優先右上角紅底白字圓形徽章；真正 Tk 若難以可靠呈現，可用 🔔(數量)，須記錄原因與實測證據。
- [ ] 零筆隱藏徽章或數字但入口可用；零、一與多位數在兩語均不截斷、不遮圖示、不改點擊範圍與 KVM／頂列位置，不自行採 9+ 封頂。
- [ ] 透過真正 App／Tk 與實際輪次恢復情境驗證計數生命週期，提供繁中／英文可見畫面；不只測私有計數函式。

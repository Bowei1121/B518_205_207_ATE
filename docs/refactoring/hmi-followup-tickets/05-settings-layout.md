## What to build

工程師用精簡瀏覽按鈕選資料夾，配置操作兩排三等分，取消草稿獨立放在下方右側，中英文均協調可讀。

## Acceptance criteria

- [ ] 集中翻譯資源使用「📂 瀏覽／📂 Browse」，仍選既有資料夾並更新草稿；取消選擇不改原草稿，原生系統文字遵照 OS。
- [ ] 上排載入已存配置／驗證草稿／套用並保存，下排匯入配置／匯出配置／重新載入部署配置，每排三等分、等高及等間距。
- [ ] 以真正 Tk 測量欄寬，整數像素分配差至多一像素；不得以固定字元寬度當成等寬驗收。
- [ ] 取消草稿另置下方右側且可見可操作，保持原本取消效果，不刪除或擠出視窗。
- [ ] 驗證選擇與取消資料夾、草稿驗證、載入、套用保存、匯入匯出與部署配置重載的原效果，不改持久配置與驗證時機。
- [ ] 真正 App 繁中／英文無裁切，切語言保留輸入與選取，提供兩語設定頁畫面及功能證據。

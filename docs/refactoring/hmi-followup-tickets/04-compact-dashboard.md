## What to build

操作員在主頁只看到簡短 App 狀態，詳細原因與恢復操作從鈴鐺或右下診斷連結取得，停止按鈕下方不再展開大控制區。

## Acceptance criteria

- [ ] 確認 HF2 新入口可用後，移除主頁展開的未保存輪次選擇、所選重試、封存摘要及封存重試控制，功能仍能從鈴鐺到達。
- [ ] 主頁最底部顯示簡短本地化 App 狀態，不展開長摘要；故障不能被正常提示掩蓋，且使用者能由鈴鐺或診斷查到詳情。
- [ ] 右下「診斷」為可用滑鼠與鍵盤操作的本地化連結，開啟原 App 事件視窗，不將 App 診斷混入鈴鐺通知數。
- [ ] App 事件保存與語言刷新失敗的說明、原始診斷及重試在適當診斷入口可用，移除主頁原重試文字等常駐操作前先驗證替代入口。
- [ ] 從新入口完成可控故障恢復，成功後簡短狀態反映恢復；關閉保存仍可重試或取消，視窗可操作。
- [ ] 真正 App 兩語驗證主頁簡潔、底部狀態與連結可見、固定位置及切語言不丟狀態；提供畫面與互動證據。
- [ ] 不擴大主頁固定寬度，不任意移動 KVM 辨識區；回歸監控控制、人工裁決及完整保存才關閉。

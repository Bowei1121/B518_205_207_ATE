## What to build

驗收人員能在整合後真正 App 完成異常出現、查看、處理、恢復及正常關閉，並確認兩語整體視覺與 KVM 契約。

## Acceptance criteria

- [ ] 核對全部 44 項使用者故事與前六票證據；沿用有效證據，只補缺漏與整合風險，不無條件重跑前票全部測試。
- [ ] 以真正 App 串接異常產生、通知計數、開窗查看、保存／封存重試及警報確認、狀態恢復到正常關閉，驗證部分成功、再失敗及取消關閉。
- [ ] 提供繁中／英文主頁、通知視窗、設定配置及保存期限頁畫面，涵蓋零值、異常、多位數、故障與語言切換；確認圖示可辨識、比例、可讀性與固定位置。
- [ ] 切換語言保留選取、輸入、展開與閱讀位置，保持關閉保存期間既有語言切換限制，不自動確認或重試。
- [ ] 確認主頁大型控制區已收納且所有原恢復功能有入口，診斷詳情與語言更新重試可用，清理摘要不空白／跳動。
- [ ] 完成有意義的監控、人工裁決、KVM 色帶及狀態標記、資料完整保存與關閉契約回歸；不只檢查 widget 存在或 image 屬性。
- [ ] 記錄真正桌面環境與尚未驗證環境，不用原型或舊驗收宣稱本次已完成；工廠驗收另列，不阻擋程式及桌面驗證完成後整合。
- [ ] 不引入與本次無關的大量歷史查詢效能驗收或數小時資料量測試；未修改判定、資料格式與清理政策。

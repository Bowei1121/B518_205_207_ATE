## 執行方式

- 可開始的功能票為 HF1、HF2、HF5、HF6；HF3 等 HF1／HF2，HF4 等 HF2，HF7 等前六票。僅開始所有前置完成的票。
- 無功能依賴不表示可同時改同一介面模組；若分 worktree 並行，要協調共享程式修改及整合順序。真正 Tk 桌面驗證避免同桌面互搶焦點。
- HF2 先建立可用鈴鐺恢復入口並保留舊主頁入口，HF4 再移除展開區，確保遷移期間恢復操作不中斷。無須另加純重構前置票。
- HF7 重用前票有效證據，只補整合與缺漏驗證；不加入與本次無關的數小時大量歷史查詢驗收。
- 圖示替代素材需使用者確認；不得拿純原型、image 屬性或舊驗收替代真正 App 畫面辨識驗收。
- 工廠驗收可另列，不阻擋程式與桌面驗證完成的票整合。不修改／關閉父規格議題正文與狀態。
- 遠端使用原生子議題及阻擋關係，票內文字另保留依賴供本機查閱。全部標記 ready-for-agent；有未完成前置的票不可提早認領。

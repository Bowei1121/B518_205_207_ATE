## Acceptance criteria

- [ ] 核對 52 項使用者故事、全 App 按鈕清單與前七票證據，補齊動態／停用／不同視窗控制覆蓋，不僅抽查頂列。
- [ ] 重用有效前票證據，只補缺漏與整合風險；驗證 1／10／11／20、較小高度、末列可達及固定欄寬，KVM 幾何與語意色維持。
- [ ] 兩徽章零值、事項產生、開窗、裁決／恢復到數量更新均正確；Logo 比例及頂列位置穩定、徽章不裁切或遮擋，地球選單滑鼠及鍵盤可用。
- [ ] 驗證全 App 適用按鈕的提示、翻譯及狀態已覆蓋，代表性實際控制測懸停、Tab／Shift+Tab、按下、停用與可用狀態轉換，不以鏡像實作測試取代行為。
- [ ] 提供試行樣式真正繁中／英文畫面供辨識度與可讀性確認，保留短標籤；無殘留提示、焦點被奪、意外動作或定時回呼錯誤。
- [ ] 真正系統深淺外觀、已開恢復視窗切換外觀、切分頁／語言與重開後仍可讀，外圍留白淺色、選取及閱讀狀態維持。
- [ ] 必要回歸涵蓋監控、裁決、警報、保存封存重試、取消關閉與完整保存才關閉；明記已測及未測環境。
- [ ] 未提交暫稿及舊驗收不當成本次完成；工廠項目另列而不阻擋已完成桌面驗證的票整合，不加入無關數小時效能驗收。

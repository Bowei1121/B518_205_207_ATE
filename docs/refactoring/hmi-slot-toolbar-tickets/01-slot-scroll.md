## What to build

操作員可在淺灰空白區的 Slot 表格一次讀取最多十項，小螢幕減少列數且所有資料仍可捲動到達。

## Acceptance criteria

- [ ] 表格資料下方空白改為主頁淺灰；資料欄位、黑框、產品狀態語意色及 KVM 超出容量黑格維持。
- [ ] 空間足夠時容量一至十全部可見，十一以上最多十列；小螢幕依實際高度減少列數，不縮字、不以裁切末列冒充完整顯示、不將操作區擠出畫面。
- [ ] 捲軸固定保留欄位，全部內容可見時淺灰停用且不能拖移；實際超出可視範圍才啟用，即使十項內亦適用。
- [ ] 改機型、容量及可用高度時重新判斷捲動，內容減少時修正非法位置；捲軸啟用變化不造成欄寬跳動。
- [ ] 真正 Tk 驗證 1／10／11／20 項與足夠／不足高度、原字體、主要操作可見性、末列完整可達及 KVM 幾何；不只斷言 disabled 或樣式值。

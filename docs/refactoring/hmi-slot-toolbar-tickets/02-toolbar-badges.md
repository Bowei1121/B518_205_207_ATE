## Acceptance criteria

- [ ] 維持左側設定／Logo 與右側待確認／鈴鐺／語言排列及主頁固定寬度，整排圖示和 Logo 垂直對齊。
- [ ] Logo 保留原比例縮小至一般按鈕可見高度，徽章浮出高度不納入；載入失敗仍保留配置空間，不顯示 B518 LOG 替代。
- [ ] ⚠️ 採右上角圓形紅底白字事項數，零筆隱藏；沿用待確認事項，不新增去重或併入鈴鐺，開窗不清零、完成裁決依既有狀態減少。
- [ ] 兩徽章保留完整頂部及相鄰空間，鈴鐺可向左下調整但不任意搬動 KVM 區；零、一及多位數不截斷、不覆蓋鄰近入口、不自行改為 9+，數量及語言變動不推動按鈕。
- [ ] 🌐 僅圖示、移除原生箭頭與過量留白，不靠裁切元件藏箭頭；保留足夠點擊範圍、目前語言、選單選取／取消、鍵盤開啟與 Tab／Shift+Tab。
- [ ] 原鈴鐺計數、恢復效果及關閉保存期間語言切換限制維持。
- [ ] 真正輪次情境驗證待確認生命週期；兩語畫面量測 Logo 比例、頂部範圍、按鈕與徽章不相交、KVM 定位及格位；不只塞假計數標籤驗收。

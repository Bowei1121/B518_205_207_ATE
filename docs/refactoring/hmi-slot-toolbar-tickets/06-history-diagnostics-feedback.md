## What to build

操作員在歷史查詢、分頁、取消及診斷操作中取得正確雙語提示及可用狀態回饋，背景查詢與保存狀態轉換不留過期提示。

## Acceptance criteria

- [ ] 沿用 ST3 能力覆蓋查詢、分頁、取消、詳細及 App 診斷相關按鈕／連結與動態操作，更新全 App 清單。
- [ ] 功能、效果及快捷鍵與現有操作一致；停用可查說明及已知原因，短標籤保留；不更改查詢資料或診斷保存政策。
- [ ] 真正查詢或保存的啟用／停用轉換下，懸停／焦點／按壓樣式及說明正確更新，滑鼠移出不清除仍存在的鍵盤焦點。
- [ ] 確認提示不觸發新查詢、翻頁、取消或重試，不搶焦點、不清除輸入、選取與閱讀位置。
- [ ] 切語言及關窗／重開後無舊語言說明、殘留浮窗或定時回呼錯誤；雙語長說明在實際螢幕可讀。
- [ ] 以適量真實暫存事件及既有測試入口驗證，不因提示變更重跑數小時大量資料效能驗收；提供兩語畫面及操作證據。

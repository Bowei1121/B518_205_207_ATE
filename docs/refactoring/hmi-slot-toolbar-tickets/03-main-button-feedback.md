## What to build

操作員從主頁所有按鈕讀到目前語言的功能說明，並能分辨懸停、鍵盤焦點、按下與停用狀態；建立後續視窗可沿用的能力。

## Acceptance criteria

- [ ] 盤點全 App 自有按鈕及按鈕功能的連結、圖示、選單入口，包括動態與停用控制，建立後續分批覆蓋清單；本票先完整落地主頁，不只交付工具類別。
- [ ] 可用按鈕懸停淺藍底，焦點藍框持續至焦點離開，兩者並存；按下更深、釋放依當下狀態還原。停用灰色且無可點擊懸停／按壓效果，可用狀態變更不殘留舊樣式。
- [ ] 滑鼠停留及鍵盤聚焦可讀目前語言的用途、操作效果與適用快捷鍵；停用按鈕可由滑鼠取得功能及已知不可用原因，不猜原因、不強迫停用控制取得焦點。
- [ ] 沿用既有提示能力，處理仍聚焦而滑鼠移出等並存條件；語言及原因變更時更新，選單展開、控制銷毀、關窗無殘留提示或定時回呼錯誤，不搶焦點／觸發操作。
- [ ] 保留短標籤及已確認純圖示，不批次清空文字；翻譯集中並沿用英文回退，不顯示內部識別碼。
- [ ] 用真正主頁滑鼠及鍵盤驗證狀態轉換、長提示可讀、開關視窗與語言更新；提示不遮 KVM 狀態標記、樣式不改幾何。
- [ ] 淺藍與藍框屬試行方向，提供真正中英畫面供確認，不把產生色值視為最終視覺核可。共通規則可採代表性控制測完整狀態，不寫每標籤的鏡像實作測試。

## What to build

## Acceptance criteria

- [ ] 沿用 ST3 能力完成設定所有分頁及通知恢復兩分頁的適用控制覆蓋，包含瀏覽、配置、保存期限、動態重試及連結；更新全 App 清單。
- [ ] 繁中／英文功能說明與快捷鍵符合實際效果，已知停用原因可查；保留開始／保存等短標籤，不改配置或恢復操作範圍。
- [ ] 驗證滑鼠及 Tab／Shift+Tab 的懸停、焦點、按下、停用與狀態變更；說明出現不代表停用控制可執行。
- [ ] 語言切換、切分頁、關閉／重開與控制重建後，提示正確更新且無孤立浮窗／定時工作，輸入、選取及閱讀位置維持。
- [ ] 從真正設定及恢復操作確認效果維持，包括取消資料夾、草稿操作、保存／封存重試；不以增加 tooltip 字串就判定功能完成。
- [ ] 提供兩語對應畫面與互動證據；不依賴 ST7 才能交付提示，若同時修改外觀則協調共享程式並在最終整合驗證。

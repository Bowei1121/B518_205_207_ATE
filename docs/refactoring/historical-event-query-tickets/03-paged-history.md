# H3：完整分頁與按需查看詳細資料

## Parent

規格：[GitHub #37](https://github.com/Bowei1121/B518_205_207_ATE/issues/37)。

## What to build

操作員以純左右箭頭查看完整查詢結果，每頁最多100筆；事件詳細按需取得，翻頁不重掃所有來源，結果不隨新事件自動移動。

## Acceptance criteria

- [ ] 提供純左右箭頭、頁面資訊與首末頁停用方向；0／1／100／101／多頁情境皆正確。
- [ ] 事件身分與穩定排序跨頁一致，不重複漏筆；換頁保留查詢範圍，正常換頁不重新掃描全部來源。
- [ ] 結果使用精簡、可回收的查詢資料或暫存管理，不先將全部原始事件物件與診斷載入記憶體再切頁；詳細只按選取取得。
- [ ] 提交查詢時固定已取得事件集合與來源邊界；後續新增事件按查詢才納入，翻頁不混入新事件。
- [ ] 適用混合來源並維持原文／雙語呈現；可驗證地查看首批之後的所有頁面，替換H1首批階段提示。
- [ ] 公開查詢／翻頁／詳細入口及真正Tk驗證結果集合、箭頭與選取；同時保留後續索引加速的責任邊界，原始來源bytes不變。

- [ ] 完成此票必要測試、真正桌面驗證及相關回歸後可合併；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

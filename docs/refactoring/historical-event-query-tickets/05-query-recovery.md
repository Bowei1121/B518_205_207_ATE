# H5：異常提示、索引降級與重試

## Parent

規格：[GitHub #37](https://github.com/Bowei1121/B518_205_207_ATE/issues/37)。

## What to build

部分來源無法讀取或日期無法判定時，正常資料仍可查且可查看異常；索引故障不阻擋查詢，以背景回讀及後續重試恢復。

## Acceptance criteria

- [x] 索引遺失、損壞、版本不支援、讀寫權限／磁碟錯誤及中斷建立可安全降級或重建；提示加速資料不可用、這次可能較慢。
- [x] 降級仍保有分頁、按需詳細與Tk回應，不因改讀原檔又同步載入全部事件到畫面。
- [x] 壞檔、無有效日期及不完整保存有不完整結果提示與查看詳細入口，保留來源、原文與診斷；日期未知不推測所屬區間、不混進正常日期結果。
- [x] 局部成功可發布正常結果但標明不完整；全部不可讀不能只顯示沒有事件，整次查詢失敗保留舊結果與範圍。
- [x] 異常詳細按需呈現，不一次插入大量錯誤文字；失敗或來源變動未確認者不快取成成功，下次可重試。
- [x] 真實暫存來源與真正Tk驗證故障、恢復、重查及切語言時可理解說明與原始診斷，回讀原檔基準一致且來源不改寫。

- [x] 完成此票必要測試、真正桌面驗證及相關回歸後可合併；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

逐項證據及 runtime 限制見 [H5 local validation](../evidence/historical-event-query-ticket-05/local-validation.md)。勾選只代表本票程式與必要桌面驗收，不代表 H6–H8、父規格、正式部署或工廠驗收完成。

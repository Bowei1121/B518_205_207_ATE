# H6：固定結果與保存、清理共存

## Parent

規格：[GitHub #37](https://github.com/Bowei1121/B518_205_207_ATE/issues/37)。

## What to build

查閱中的固定結果不阻擋保存與期限清理；來源已刪除或替換時清楚指出不可取得，不冒充原事件或混入新內容。

## Acceptance criteria

- [ ] 正式保存新增事件不自動改動目前集合，再次查詢才更新；查詢只是已保存來源的視圖，不要求監控writer額外flush。
- [ ] 已載入內容可繼續查看；尚未載入來源被清理時在原事件位置提示不可取得並建議重查，不補其他事件或誤報紀錄損毀。
- [ ] 來源版本被替換且原版無法取得時同樣不得把新內容當舊固定結果；查詢讀取期間變動需驗證、重讀或標示未確認，不要求跨來源交易鎖。
- [ ] 查詢視窗不延後合法清理；來源刪除讓衍生索引失效，不改ledger、保存期限、可信封存起算或待確認／未保存保護。
- [ ] 以正式保存／清理公開入口、真實磁碟與全新讀取器驗證競態及契約一致，真正Tk驗證提示位置、已載入內容與重查。
- [ ] 維持ADR0007／0008／0009：監控結果、裁決、雙語同筆、保存成功才關閉及原始bytes契約不因查詢而改變。

- [ ] 完成此票必要測試、真正桌面驗證及相關回歸後可合併；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

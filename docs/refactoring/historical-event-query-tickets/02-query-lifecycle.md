# H2：重新查詢、取消與視窗生命週期

## Parent

規格：[GitHub #37](https://github.com/Bowei1121/B518_205_207_ATE/issues/37)。

## What to build

查詢等待中仍能編輯條件、重新送出或取消；保留舊結果，以最新有效查詢為準，視窗關閉重開不受舊回傳干擾。

## Acceptance criteria

- [x] 送出時固定日期／時區與查詢世代；僅編輯條件不使目前結果失效，也不把舊結果誤標為新條件。
- [x] 重新送出採最新條件，舊工作較晚完成不得覆蓋新結果、進度或錯誤；只有有效世代可以發布結果。
- [x] 提供取消入口；取消／整次失敗保留原結果及其日期範圍，新查詢成功後才替換，無舊結果時也清楚標示狀態。
- [x] 關閉視窗取消／失效查詢，重開不接收舊回傳；過期工作協作停止，待處理請求以最新為準，不無限制產生worker。
- [x] 真正Tk搭配受控慢讀及亂序完成驗證編輯、重查、取消、關閉重開均可操作；只Tk執行緒更新元件。
- [x] 重複重查與關閉後背景工作／資源不持續累積，監控不停止，App關閉保存不因無效查詢卡住或新增保存工作。

- [x] 完成此票必要測試、真正桌面驗證及相關回歸後可合併；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

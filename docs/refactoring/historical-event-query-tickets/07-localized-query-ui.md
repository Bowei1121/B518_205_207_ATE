## What to build

## Acceptance criteria

- [ ] 查詢放大鏡、純左右分頁箭頭、首末頁停用、目前語言停留提示及可辨識操作名稱／鍵盤操作完備；不把彩色emoji顯示視為唯一實作。
- [ ] 日期條件、查詢中／取消／失敗、結果範圍與頁面等共同文案集中管理，英文／繁中完整及沿用英語回退；保留必要說明而不全以圖示取代。
- [ ] 已開視窗切語言保留未送出輸入、原結果條件、世代、目前頁面與選取；不自動提交、不改事件集合、不全量重讀磁碟。
- [ ] 查詢中或持有舊結果時切語言也可繼續操作，後續結果依當時畫面語言呈現；索引身分與排序不依文案。
- [ ] 原始SN、路徑、檔名、Log及診斷保持原值，舊原文與同筆雙語保存資料不改寫。
- [ ] 真正Tk操作圖示／鍵盤／提示、重查／取消及語言通知，驗證頁面選取與來源bytes；H5新增恢復文案由H5負責，其全狀態整合由H8驗收。

- [ ] 完成此票必要測試、真正桌面驗證及相關回歸後可合併；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

# H1：日期查詢與首批結果

## Parent

規格：[GitHub #37](https://github.com/Bowei1121/B518_205_207_ATE/issues/37)。

## What to build

操作員可選擇單日、日期區間或快捷範圍，按放大鏡按鈕才在背景查詢輪次與 App 事件；先顯示最多100筆首批結果，建立後續分頁與索引可沿用的查詢入口。

## Acceptance criteria

- [x] 開啟頁面預設最近90天且包含今天，不自動讀取；支援今天、最近7／30／90天、指定單日與自訂區間，編輯條件不自動查詢。
- [x] 缺少日期、日期無效或開始晚於結束時欄位旁提示、不提交工作、不清除舊結果；合法範圍不設90天上限，空結果與未查詢狀態可區分。
- [x] 依App觀察／記錄事件時間及工廠當地時區判定，含起訖整天；無時區舊資料直接當地解讀，帶時區事件先換算；跨午夜、月年及夏令時間23／25小時日期皆正確。
- [x] 混合正式輪次、舊紀錄與App來源；沿用來源優先與事件身分，不重複計數、不以目錄／封存／檔案日期替代事件日期。
- [x] 首批最多100筆、最新優先且同時刻有穩定身分／數字序號排序，明確標示此階段為首批結果，不誤稱已可查看全部多頁內容；不全量格式化詳細資料。
- [x] 以既有讀取／呈現契約及公開查詢入口建立可延伸流程，不讓Tk直接做全量讀檔、排序；真實暫存來源與真正Tk證明慢讀期間畫面可操作及原始bytes不變。

- [x] 此票必要測試、真正桌面驗證及相關回歸通過，固定基準 Standards／Spec 審查無阻擋，已快轉合併並完成主線重驗；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

驗收證據：[H1 local validation](../evidence/historical-event-query-ticket-01/local-validation.md)。所有勾選項均以目前分支最後程式／測試版本的結果為準；合併、推送及分支清理狀態另記於證據文件。

## Blocked by

無，可立即開始。

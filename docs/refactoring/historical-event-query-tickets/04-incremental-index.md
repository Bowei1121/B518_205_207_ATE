## What to build

首次查詢背景建立可重建索引，重啟後重用；重查只更新新增或變更來源，分頁仍按需取得詳細資料。

## Acceptance criteria

- [x] 索引為衍生資料，保存必要來源身分／版本、事件時間、識別與定位；不擴大或改寫原始保存格式，不參與清理資格。
- [x] 首次建立、重啟重用及未變更重查能取得與原檔基準相同的事件集合與日期邊界；索引只在讀取成功且來源版本確認後可標為可靠。
- [x] 新增、追加、同路徑替換、搬移、刪除及掃描期間來源變動能更新或失效；不可把內容變動誤判為未變更；App整份來源變更不強制改其保存方式。
- [x] 只有有效事件範圍可排除日期外資料；跨午夜、待確認後事件、保存重試不得因輪次開始／封存／資料夾名稱漏查。
- [x] 正常未變更重查及翻頁不完整重讀／解析已索引的所有來源；單來源變更不使其他未變更來源全面重解析，允許必要發現／版本檢查與定位讀取。
- [x] 索引及結果管理不全量駐留原始物件／詳細內容，首次整理仍背景執行；真實磁碟、重啟與I/O成本證據配合桌面查詢驗證。

- [x] 完成此票必要測試、真正桌面驗證及相關回歸後可合併；工廠驗收另追蹤，不阻擋合併。不修改原始紀錄、監控裁決或保存／清理契約。

驗收證據：[H4 local validation](../evidence/historical-event-query-ticket-04/local-validation.md)。該紀錄會在最終審查、整合、遠端同步與分支清理後追加最終 SHA 和查核時間。

# M8：歷史事件按語言顯示且不改寫舊紀錄

## Parent

Part of [規格 Issue #13](https://github.com/Bowei1121/B518_205_207_ATE/issues/13)。依 ADR 0009 及已確認拆票方案實作。

## What to build

現場與開發人員可用選定語言閱讀新舊事件；新版依訊息識別呈現、必要時使用保存英文，舊版只在可靠辨識時翻譯。不明內容保留原文詳細及翻譯外層提示，不改寫硬碟證據。

## Acceptance criteria

- [ ] 新雙語紀錄可依識別／參數重顯示，資源更新不回寫當時保存文字；不明新資源可回退保存英文。
- [ ] 舊訊息僅可靠契約匹配才翻譯，不用模糊猜測或在線翻譯，不補造參數及時間。
- [ ] 無法辨識內容原文詳細保留，外層說明翻譯；檔案讀取前後內容完全一致。
- [ ] 畫面既有事件與歷史訊息切換同步，不重跑事件，不改序號或操作結果。
- [ ] 覆蓋輪次、平台、App 診斷及新舊混合資料，真正 Tk 閱讀與磁碟相容重建通過。

# M9：App 層雙語事件按自身時間安全清理

## Parent

Part of GitHub 規格 Issue #13。草案，待確認後發布。

## What to build

工程師設定的全域保存天數同樣管理無輪次 App 事件，依原事件時間清理、保護待補存資料，並可查閱雙語維護摘要。沿用既有背景清理協調入口，不再新增獨立排程。

## Acceptance criteria

- [ ] 使用事件原時間與帶時區一致比較，不虛構封存時間；輪次仍按可信封存時間計算。
- [ ] 全域期限修改在下次清理生效，期限前、恰到及之後有注入時間證據。
- [ ] 只清理可信、完整保存、已到期的 App 事件；待保存、故障、未知及損壞資料保留。
- [ ] 同一保存段含未到期或受保護事件時不因其他到期內容誤刪整段，不碰配置、來源、人工匯出等外部資料。
- [ ] 與既有清理排程、保存及關閉協調，不重疊；摘要可用兩語查閱，清理失敗可安全重試。
- [ ] 真實暫存磁碟、注入時鐘與 App 操作驗證設定變更、邊界、競爭、故障及摘要，不以純 helper 測試代替行為。

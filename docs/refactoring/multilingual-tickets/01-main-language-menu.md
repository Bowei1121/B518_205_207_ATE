# M1：主頁直覺語言選單與上次語言持久保存

## Parent

Part of [規格 Issue #13](https://github.com/Bowei1121/B518_205_207_ATE/issues/13)。依 ADR 0009 及已確認拆票方案實作。

## What to build

操作員可在主頁右上角直接選 English／繁體中文，主頁文字立即更新，首次英文且下次開啟記住選擇。以這條完整路徑先建立集中翻譯及共用術語，其他自有視窗與事件批次於後續票接入。

## Acceptance criteria

- [ ] 按鈕顯示目前語言及展開提示，選項為原生名稱與勾選；不以國旗或語系代碼代替。
- [ ] 滑鼠與鍵盤可展開、選取及取消，不需套用或重啟；重選不改操作狀態，未支援語言不列選項。
- [ ] 首次英文、重啟記住上次選擇，設定獨立於 profile；配置保存不抹除語言，未知設定回英文，保存失敗明確可見。
- [ ] 主頁可翻譯文字集中管理，缺少單項回退英文；穩定訊息識別、參數及共用術語契約可供後續事件使用，不改狀態碼。
- [ ] 主頁即時切換不重啟監控，語言菜單與長文字不遮住 KVM 標記或色帶；真正 Tk 驗證可操作版面。
- [ ] 經 App 操作、持久設定與重啟驗證，包含無效值及寫入失敗；其他未遷移路徑保留既有相容行為，不宣告全 App 已完成。

## Blocked by

None (can start immediately).

# M1：主頁直覺語言選單與上次語言持久保存

## Parent

Part of [規格 Issue #13](https://github.com/Bowei1121/B518_205_207_ATE/issues/13)。依 ADR 0009 及已確認拆票方案實作。

## What to build

操作員可在主頁右上角直接選 English／繁體中文，主頁文字立即更新，首次英文且下次開啟記住選擇。以這條完整路徑先建立集中翻譯及共用術語，其他自有視窗與事件批次於後續票接入。

## Acceptance criteria

- [x] 按鈕顯示目前語言及展開提示，選項為原生名稱與勾選；不以國旗或語系代碼代替。
- [x] 真實滑鼠與鍵盤可展開、導覽／選取及取消，不需套用或重啟；重選不改操作狀態，未支援語言不列選項。已修正使用者確認的按鈕裁切，以及 Tk 要求 menu 隸屬 menubutton 的開啟失敗；新增真 Tk 可見區域及滑鼠事件回歸。使用者已於 `44826d4` 實際視窗確認滑鼠展開切換及鍵盤開啟、選取、取消、焦點返回全部正常；證據已保存，不以 `Menu.invoke()` 代替。
- [x] 首次英文、重啟記住上次選擇，設定獨立於 profile；配置保存不抹除語言，未知設定回英文，保存失敗明確可見。
- [x] 主頁可翻譯文字集中管理，缺少單項回退英文；穩定訊息識別、參數及共用術語契約可供後續事件使用，不改狀態碼。
- [x] 主頁即時切換不重啟監控，語言菜單與長文字不遮住 KVM 標記或色帶；真正 Tk 驗證可操作版面。
- [x] 經 App 操作、持久設定與重啟驗證，包含無效值及寫入失敗；其他未遷移路徑保留既有相容行為，不宣告全 App 已完成。磁碟、故障與第 2 項實際輸入證據均已補足。

## 本機交付狀態

M1 六項必要驗收已有證據；使用者實際滑鼠與鍵盤確認解除最後操作證據缺口，準備進行主線合併驗證。本次另修正使用者確認的窄 HMI 按鈕裁切缺陷，不能將先前的輸入補測失敗全數歸因環境。固定 Standards／Spec 審查基準維持 `dd81e4dcef781ef4c29a3310a2650827e45d0609`；最新程式／測試版本、命令及複審結果見[本機驗收紀錄](../evidence/multilingual-ticket-01/local-validation.md)。此狀態不表示已更新 GitHub Issue #14；M2～M10 及完整 App／bundle 發布驗收仍待各自交付。

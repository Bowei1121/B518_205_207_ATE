# LS5：中止、失敗與補存時保留正確監控時間

GitHub：[91](https://github.com/Bowei1121/B518_205_207_ATE/issues/91)；狀態：ready-for-agent；使用原生父子與阻擋關係。

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/86

## What to build

人工停止、逾時、取消及啟動失敗都停在正確時間；開始前失敗不清除上輪時間，保存重試不改變最後耗時。

規格覆蓋：使用情境 8, 9, 10, 11, 12, 13, 16, 17；驗收情境 T02, T03, T04, T05, T18。

## Acceptance criteria

- [ ] 人工停止、整輪／開始逾時、明確取消與受理後來源準備失敗，均以實際停止收集時刻固定該輪耗時。
- [ ] 尚未受理的新輪驗證或保存設定失敗，保留上一輪顯示時間；已受理後失敗則保留本輪經過時間。
- [ ] 人工確認、故障復位、取消或保存重試，不能把時間繼續加長或重新定案；只有下一輪受理才歸零。
- [ ] 真實磁碟保存失敗後重試及新讀取端讀回，耗時、輪次身分與停止原因一致、不漏寫、不重複。
- [ ] 停表不改既有衝突、警報、產品結果、取消與結果放行政策，也不增加必須先保存才交付的條件。
- [ ] 從實際輪次操作及必要Tk畫面覆蓋每條中止路徑；來源準備晚到或舊保存完成不得影響新輪計時。

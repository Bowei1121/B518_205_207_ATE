## What to build

App在待命至完成、故障待復位與可操作關閉期間，都顯示每半秒變化的獨立四格心跳，放在狀態標記右側。

規格覆蓋：使用情境 27, 28, 29, 30, 31, 32, 34；驗收情境 T08, T09, T10。

## Acceptance criteria

- [ ] 四格2×2與狀態標記同尺寸，純黑／純白，以二進位0～15每0.5秒前進一態，15後回0。
- [ ] 心跳不跟輪次計時一起停、不因新輪受理重設；待命、準備、監控、待確認、完成、故障待復位及可操作的關閉保存期間持續。
- [ ] 由Tk更新流程驅動，真正阻塞畫面時心跳也停，不能用背景工作或事後補算偽稱停頓期間正常更新。
- [ ] 心跳在狀態標記正右側、同一列，狀態格左移以留空間，兩個定位點與結果格維持原位、不重疊。
- [ ] 慢來源或慢保存不阻塞正常畫面；銷毀後取消自己擁有的排程，不影響外部回呼，也不留下Tk錯誤。
- [ ] 心跳不逐次寫永久事件紀錄；從真實Tk畫面驗證半秒變化、完整16態、各狀態與銷毀清理。
- [ ] 產出本地格樣與幾何樣本，最終遠端像素門檻與兩組必要放大由LS7實測定稿。

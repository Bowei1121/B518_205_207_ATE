- [ ] 以同一整合版本驗收開始、監控、待確認、正常／人工停止、逾時、取消、故障復位、保存重試及關閉；確認計時與心跳各自正確。
- [ ] 歷史查詢全流程與新計時／心跳共存，舊回覆、取消、關窗及語言切換不干擾本輪或計時區。
- [ ] 既有結果交付、未知來源、衝突、警報、取消與保存完整性門檻不退步，不跳過既有失敗測試求通過。
- [ ] Python3.12.10及指定套件下執行相關自動測試與真實Tk操作，包含長狀態、中英文、不同容量／縮放與原生輸入。
- [ ] 提供原生arm64打包、bundle檢查、簽章及M4／macOS15目標機證據；Intel結果不能替代。缺少目標設備須如實標示未驗收，不直接結票宣稱完成。
- [ ] 記錄最終App commit／版本、環境、測試輸出、顯示契約及Claude交接版本；區分已完成App驗收與需外部接續的橋接配對。
- [ ] 沒有橋接新版或配對環境時，不宣稱跨專案驗收通過；文件明確列出待配對項目與現場部署前提，仍完成可執行的App本地驗證。
- [ ] 本票不擴充新的產品政策、不修改橋接程式，也不關閉或改寫父規格Issue。

# LS2：統一開始監控與正確的失敗原因

GitHub：[88](https://github.com/Bowei1121/B518_205_207_ATE/issues/88)；狀態：ready-for-agent；使用原生父子與阻擋關係。

## Parent

https://github.com/Bowei1121/B518_205_207_ATE/issues/86

## What to build

操作員由按鈕或快捷鍵開始得到一致行為，故障顯示真正原因、保留紀錄並須明確復位，不會重複建立輪次。

規格覆蓋：使用情境 46, 47, 48, 49, 50；驗收情境 T04, T17, T18。

## Acceptance criteria

- [ ] 先集中既有開始流程的非畫面協調，保留配置固定、平台資料來源及位置映射；畫面不另維護重複受理規則。
- [ ] 按鈕與快捷鍵共用開始限制；重複操作、關閉中、待復位或既有不可重入輪次，不得建立第二輪。
- [ ] 分別從實際開始入口觸發配置驗證、設定保存、來源建立／啟動及呈現錯誤，畫面與紀錄須對應真正失敗步驟。
- [ ] 監控已受理或啟動後呈現出錯，不把輪次當成不存在，也不一律說成設定保存失敗。
- [ ] 原始診斷、輪次身分、人工處理／復位與不自動重試政策維持；保存失敗不得漏寫或重複。
- [ ] 準備中停止後，即使來源工作晚到也不重新開測；完成端到端輪次與必要真實Tk按鈕／快捷鍵驗收。
- [ ] 此票不先加計時功能，不以大量轉呼叫module或同時保留兩套開始規則作為完成。

## Blocked by

None（可立即開始）。

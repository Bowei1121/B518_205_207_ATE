## What to build

橋接維護者取得最終狀態／心跳／計時座標、實際KVM影像、辨識規則與版本對照，可據此接續橋接修改。

規格覆蓋：使用情境 21, 23, 24, 25, 26, 33, 34, 35, 36, 37, 38；驗收情境 T07, T10, T11, T12, T13。

## Acceptance criteria

- [ ] 以合併後的計時與心跳App量測實際接收的縮放／壓縮影像，遠端每小格至少12×12像素；不足時兩組同時放大並驗證無重疊。
- [ ] 凍結顯示契約版本、狀態／心跳各小格、間隔／留白、計時裁切範圍、字型／顏色及容量／語言／縮放樣本；不得把Tk單位當遠端像素。
- [ ] 定位點與結果格維持原位；分別遮住狀態、心跳及結果驗證可讀性，不能因相鄰就假定同時可見。
- [ ] 交接明訂每秒觀察下的三張有效同圖定義、約2秒跨度、8秒循環、壓縮雜訊與舊影格限制；附正常與凍結樣本及可重現驗收步驟。
- [ ] 明確區分計時啟動輔助、監控就緒、ATE活動與可交付結果；包含上輪時間殘留、準備中、正常停表仍有心跳及快速完成案例。
- [ ] 更新Claude交接資料與App／橋接相容版本說明，舊座標不能冒充新契約；本票不修改橋接、TCP或LabVIEW。
- [ ] 最大觀察間隔、中斷重設、恢復門檻與上位機錯誤處置留給Claude工作定案，不標成已確認；提供資料不等於橋接已完成配對。
- [ ] 缺少實際KVM擷取環境時，完成可用本地證據並明列此票遠端量測尚未通過，不以合成圖宣稱滿足像素門檻。

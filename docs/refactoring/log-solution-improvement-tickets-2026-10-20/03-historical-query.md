## What to build

操作員照原方式查詢、翻頁、看詳細、取消、重試與切換語言；舊回覆不蓋新畫面，固定查詢結果及閱讀位置維持。

規格覆蓋：使用情境 39, 40, 41, 42, 43, 44, 45；驗收情境 T14, T15, T16。

## Acceptance criteria

- [ ] 由歷史事件查詢完整操作入口驗證首次公布、後續準備、翻頁、詳細、診斷、取消、重試及關窗，集中共同狀態與結果擁有權。
- [ ] A查詢後送B，A晚回不能蓋B；舊分頁及詳細結果亦不得覆蓋較新的選擇。
- [ ] 取消後仍可讀的已公布結果保留；重試延續同份固定結果，不悄悄重查來源或改變已公布內容／排序。
- [ ] 來源新增、替換、清理或無法取得資料時，保留固定結果契約並如實回報，不能補造遺失資料。
- [ ] 中英文切換保留日期草稿、頁面、選取與閱讀位置；關窗重開不被舊工作反寫。
- [ ] 讀取中的結果不可提早釋放，關窗後不可遺留工作或資源；以原有查詢與真實Tk案例驗證，而非只測小函式。
- [ ] 整理已棄用UTC轉換寫法時維持既有時區及回傳語意；不順便改成逐SN生產報表。
- [ ] 移除已遷移的重複規則；只搬計時器、拆檔或新增轉呼叫module不算完成。

# HC3 固定視窗驗收

驗收入口為正式 Tk/Aqua App。啟動時計算一次固定視窗高度：以畫面可用區（macOS `NSScreen.visibleFrame`）、主畫面控制項的實際需求高度、列高 33 Tk px、32 px 視窗裝飾保留量及上下各 8 px 邊界間距決定可視列數。裝飾保留量比本機量到的 28 px 多留 4 px。計算不讀取測試容量；後續容量、語言、長狀態、提醒及計時更新都沿用該視窗和表格可視區。

## 實測尺寸與支援條件

| 螢幕可用尺寸 | Tk 視窗 | macOS 原生視窗 | 可視列 | 結果 |
| --- | --- | --- | ---: | --- |
| 1440×900，頂部系統保留 25 px | 376×806，位置 +1052,+33 | 376×834，含 28 px 標題列 | 8 | 正常尺寸；容量 1／10／11／20 與中英文幾何一致 |
| 1152×720，頂部系統保留 25 px | 376×641，位置 +764,+33 | 376×669，含 28 px 標題列 | 3 | 小螢幕實際驗收通過；開始、狀態、計時、停止及診斷操作完整可見 |

本次固定控制項實際需求高度為 542 Tk px，計入一個 33 px 通道列、32 px 裝飾保留量、上下各 8 px 邊界及本機系統保留區後，最低支援高度為 648 px。此門檻依目前 macOS/Tk/Aqua、14 pt 字體、佈景與控制項需求成立；若字體或控制項需求增高，程式會以新量測值提高門檻。固定寬度為 376 px，含右側 12 px 邊界的適用寬度至少 388 px。低於門檻的螢幕不列為支援條件。

主畫面量測使用 `NSScreen.visibleFrame` 排除系統保留區；本機兩種螢幕高度的頂部保留均為 25 px、底部為 0 px。原生視窗比 Tk client 高 28 px，程式採 32 px 保留。1152×720 是本機可用的實際顯示模式；測試切換後確認恢復為原本的 1440×900。

## 間距與固定區前後比較

改版前使用已合併 HC2 commit `dc79be1` 的原始 UI 程式，在同一台 1440×900 螢幕量測；改版後使用真 App 截圖與元件座標。容量 1 的表格到開始鍵間距從 99 px 降到 4 px；容量 10 從 33 px 降到 4 px；容量 11／20 也從 33 px 降到 4 px。所有容量的新間距相同，少量通道留下的空間位於表格背景內，不計入表格外間距。

改版前主視窗高度會隨容量在 606／804／831 px 間改變，KVM 色帶也在 61／88 px 間切換。改版後四種容量皆為 376×806，KVM 色帶固定 88 px，開始鍵、狀態、計時與提醒區座標完全相同。容量 1 仍只建立一個通道列。40 px 高的提醒區會一直保留；計數歸零時文字清空但區域不收縮。完整座標列在 [`hc3-before-after-geometry.json`](hc3-before-after-geometry.json)，矩陣座標採 Tk client 左上角為原點。

## 提醒與長計時驗收

提醒使用與鈴鐺徽章相同的待處理計數來源，並提供英文及繁體中文文字。測試涵蓋 1／1,234 件及 123,456,789 件真 App 畫面；切換語言、顯示或清空文字都不改變視窗、表格、開始鍵、狀態、計時與固定提醒區幾何。HC4 的閃爍效果不屬於本次修正。

長計時測試以實際 Menlo 字型量測 `600:00`、`1000:00`、`10000:00`，欄寬至少容納完整字串且右緣固定；`10000:00` 實測字寬 64 px、標籤寬 68 px。證據：[`hc3-long-timer.json`](hc3-long-timer.json)、[`10000:00` 真 App 截圖](hc3-timer-10000-zh-TW.png)、[英文 1,234 件提醒](hc3-reminder-en-1234-en.png)、[繁中 1,234 件提醒](hc3-reminder-zh-TW-1234-zh-TW.png)、[英文九位數提醒](hc3-reminder-en-123456789-en.png)、[繁中九位數提醒](hc3-reminder-zh-TW-123456789-zh-TW.png)。每張提醒截圖旁有對應 JSON，含文字、計數、區域尺寸及視窗幾何。

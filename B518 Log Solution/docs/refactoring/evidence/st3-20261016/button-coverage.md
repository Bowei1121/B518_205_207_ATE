## ST3 真實桌面核對

- 主頁 8 個操作入口已列入盤點；主頁的設定、待確認、警報、語言、開始、停止、保存重試及診斷入口均有用途／效果說明，快捷鍵僅標在開始監控。
- 四個底部按鈕在兩種語言下以真正 App/Tk 取得提示；原生滑鼠操作實際展示開始按鈕 hover、focus、pressed，以及停用停止按鈕 hover 可讀、pressed 不成立及命令不執行。
- Shift+Tab 由診斷入口移到開始監控，焦點提示沒有奪焦或啟動輪次。滑鼠離開後仍聚焦的提示保留；切語言更新已顯示文字。
- 互動前後比較主頁按鈕幾何、KVM 結果區位置／尺寸及全部 Slot 顏色，均相同。提示、懸停、焦點、按下與停用 hover 沒有改變 KVM 顯示契約。
- 淺藍 hover 與藍色焦點框仍屬試行樣式，這些畫面是供使用者辨識與決定的實際呈現，非視覺核可紀錄。

其他票狀態明確留為待驗；ST4–ST6 完成時更新各列、控制狀態與對應雙語真實畫面證據，ST8 再核對全清單。
